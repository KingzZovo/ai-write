# 《无名者的第七次登记》总规划(百万字级)

**定位**:西式玄幻 × 北欧神话 × 现代社会 · 架空世界
**规模**:**5 卷 / 500 章 / 约 105 万字**(每章 2000–2200 字,每卷 100 章 ≈ 21 万字)
**主角基调**:草根、废柴、被低估(参考《龙族》路明非),但他的平庸是**真的**,而世界需要的正是这一点
**版本**:v2(2026-11-21)—— 按百万字规模重做结构,第一卷章纲保留可执行粒度的开篇 24 章

---

## 一、立意与主题

> **诸神黄昏之后,命运登记处给每个人都排好了位置;只有一个人的名字被写错了两次 —— 而他这辈子最擅长的事,就是把错就错地活下去。**

**主题句**:命运不是被反抗的,是被登记的。

**为什么它撑得住百万字**:全书真正的冲突不是"打谁",而是**两套秩序之争**——
- **登记秩序**(VEC/乌尔德局):危险但可控,代价是所有人被安排;
- **拆解秩序**(芬里尔教团):自由但会带来第二次黄昏。
主角既不是救世主也不是破坏者,他是**系统里的一个空值**:预言算不到他,所以只有他能做"剧本外"的选择。
每一卷都在加深这个问题(V1 发现自己是空位 → V2 发现笔记系统怎么运作 → V3 发现有人需要空位 → V4 发现空位是唯一的活口 → V5 用空位改写规则),这就是长篇的引擎。

**反套路承诺**:没有血脉觉醒横扫全场;没有"废物变最强"。他最后赢了,但方式是把**自己的存在本身**划掉。

## 二、世界设定

### 2.1 形态

架空,文明程度等同现代(智能手机、地铁、外卖、社交平台、社保编号、共享单车)。
北欧神话不是消失,而是**碎掉了**:诸神黄昏把九界打碎重组,神格碎成"符文残片"沉进人间。现代社会建立在这堆碎片上,却**装作什么都没发生**。

### 2.2 九界叠加(城市地理 —— 长篇的主要舞台库)

| 现代地标 | 神话对应 | 现场表现 |
|---|---|---|
| 金融区玻璃幕墙群 | 阿斯加德残影 | 雷雨天高层共振,电梯里听见号角 |
| 老码头集装箱区 | 尼福尔海姆裂隙 | 雾中脚步声不属于任何活人 |
| 地铁环线 | 彩虹桥残余 | 运行图上有三站不对公众开放:乌尔德、密米尔、斯卡迪 |
| 城东废弃钢铁厂 | 穆斯贝尔海姆 | 炉温夜里自己上升,火种未熄 |
| 殡仪馆后山 | 海姆冥界入口 | 死亡登记偶尔"多签一次名" |
| 大学城图书馆地下 | 世界树根系 | 地下三层之下还有七层(V4 主战场) |
| 城北水厂 | 密米尔之泉 | 喝过的人会"知道不该知道的事" |
| 郊区风电场 | 巨人国边界 | 叶片夜里转反方向 |

**长篇用法**:每卷启用 3–4 个舞台,反复回访但每次揭示新一层 —— 不靠不断开新地图,而靠**同一地点深挖**。

### 2.3 力量体系与代价(铁律)

力量叫**铭**(Rune)。铁律:**一切力量都用"存在感"换**。

| 体系 | 作用 | 代价 |
|---|---|---|
| 刻铭 Rune-carving | 在物/身上刻符,短暂改写局部规则 | 消耗**记忆**:每刻一次忘掉一段往事 |
| 英灵契 Einherjar Pact | 与死者残魂签约,借其技艺 | 人格被侵蚀,越来越像那个死人 |
| 命运丝 Norn-thread | 看见/拨动概率 | 被**诺恩记账**:此后每次选择都被记 |
| 立碑 Stela | 把一条规则钉进现实(领域级) | 永久失去一段"可能性" |

**等级**:无铭者 → 单铭 → 三铭 → 立碑者 → 无名(不需要铭文)
**禁忌**:同刻两枚**本源铭**(火/冰/雷/死)→ **黄昏化**:皮肤下浮灰白的光,人慢慢变淡消失(V3 起频繁出现)

**长篇用法**:代价必须**真实生效且不可逆** —— 主角忘掉的东西会在后续章节变成缺口(V3 揭出"记忆被别人收着"),这是跨卷引擎。

### 2.4 组织

| 名称 | 表面 | 实际 |
|---|---|---|
| **瓦尔哈拉余烬理事会(VEC)** | 文化遗产保护基金会 | 守界者:压制裂隙、清记忆、处理"多出来的人" |
| **乌尔德局** | 民政局"特殊档案处" | 命运登记:给每个接触铭的人建档,预测死期 |
| **斯卡迪学院** | 私立职业技术学院 | 培养刻铭者;录取不申请、不拒收、不退学(条例漏洞) |
| **芬里尔教团** | 网络社群/读书会 | 要拆登记系统,认为"秩序即牢笼" |
| **无名会** | 不存在于任何档案 | 全书最大伏笔:被登记删掉名字的人 |

## 六、百万字的可持续性设计(防中段疲软)

| 手段 | 做法 |
|---|---|
| **每卷一个独立小高潮** | 卷一老雅各布立碑 / 卷二他第一次付代价 / 卷三托维重伤 / 卷四见到另一个自己 / 卷五划名 |
| **同一舞台深挖** | 老码头、环线封闭站、钢铁厂、殡仪馆后山反复回访,每次多揭一层(不开新地图) |
| **代价真实累积** | 每一次刻铭/拨丝都留下永久缺口,后卷必须面对(读者能感到"东西在减少") |
| **双线交替** | 主线(登记系统)+ 日常线(房租、外卖、社区大学),日常线提供节奏缓冲与笑点 |
| **不写纯过渡章** | 每章至少一个新信息 + 一个未解问题;禁"总结章""回忆章" |
| **人物弧可见** | 每个配角每 20 章必须有一次立场变化(哪怕很小) |
| **信息增量表** | 每卷结束更新"读者已知 / 主角已知 / 各组织已知"三张表,避免设定打架 |

## 七、写作硬约束

| 约束 | 说明 |
|---|---|
| 主角的无能必须**具体** | 超时、算错钱、嘴比脑快;不许反复自我贬低;每次失败要推进信息 |
| 神话只以**残留**形态出现 | 碎片、故障、多签的名字、封闭站名;禁止"神下凡讲设定" |
| 神话用名准确 | 只用:诺恩(命运)、英灵殿(亡者契约)、世界树(根系)、尼福尔海姆(雾与死)、穆斯贝尔海姆(火)、芬里尔(束缚与挣脱);不混希腊/凯尔特神名 |
| 力量不升级爽文化 | 每次得能力必付具体代价,且代价在后续章节真实生效 |
| 不靠旁白解释世界观 | 通过事件(多签的名字、封闭站台)给读者 |
| 单章 2000–2200 字 | 章级目标 2100,验收线 95% |

## 八、执行方式(分卷跑)

| 步 | 动作 |
|---|---|
| 1 | 本规划评审通过(当前步骤) |
| 2 | 用系统生成**全书书纲**(5 卷规模)→ 逐卷生成**卷纲**(含 100 章章级摘要) |

| 5 | 单卷 100 章 ≤ 系统上限 200,合规 |
