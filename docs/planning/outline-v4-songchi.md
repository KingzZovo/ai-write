# 大纲 v4:主角改成路明非那种废,城市改成中文语境的现代都市

> 改动只有两处:主角(按路明非式"废"重写)、城市语感(中文语境的现代都市 + 北欧底层规则)。
> 世界规则(诺恩纺线 / 价目表 / 编织局)、第一卷四幕结构不变。

## 一、主角:宋迟,22 岁

**他不是"手艺不稳的临时工",他是那种在哪儿都排最后的人。**

- 大专念到第二年退学,理由是"念不下去",具体原因他从不讲。
- 现在在**临江市殡仪馆上夜班**,活儿是接尸、擦身、看炉子、抬担架,一个月两千八,交五险之前。
- 母亲在城东安和疗养院,一个月三千二,他出两千,剩下的靠他妈那点退休金。
- 住在老城区一栋筒子楼的六层,冬天窗户缝里塞报纸。屋里最值钱的是台二手笔记本,里面装着一款**七月就要停服的老网游**,他每天打两局,不是喜欢,是打完就能睡着。
- 楼下有个炸串摊,摊主女儿**在市医院做护士**。他每次下楼都绕开那个摊子——不是不喜欢,是他想不出说什么。

**他的废是这样的:**

| 表面 | 底下 |
|---|---|
| 被师傅骂"你这手是借来的?",他回一句"借的还带利息",然后照样抖 | 他记得师傅上次骂他之前,先去洗手间洗了把脸——师傅那天家里出了事 |
| 让他去跟家属说价钱,他站在门口十分钟,最后说"我去叫老王" | 转身他自己垫了两百块给那家买纸钱,谁都不知道 |
| 出事先走(借口通常是"我去拿工具") | 走到门口又回来,回来的时候自己都说不清为什么 |
| 每天说"这破班我明天就辞" | 已经上了十四个月 |
| 嘴上最会算账 | 别人欠他多少他记不住,他欠别人的记得清清楚楚 |

**他唯一算"本事"的东西**:收线的人会被剪掉记性,他不光记得住,还会梦到——那些死人不该被记住的事,全堆在他脑子里。这不是什么天赋,让他夜里睡不好,白天恍惚,还因此被人当成"脑子有病"。

**他不是不能变强,是他根本不想。** 他只想把这个月的两千八挣到手,把疗养院的单子交上,然后回去把那款快停服的游戏打到关服。

## 二、这座城市怎么运作(中文语境)

**临江市**,雨多、湿冷,老城区在江边,新城区在南边。市政底下有个**殡葬事务第三处**(公文名),编制十九人,管全城所有猝死。行里人不叫它三处,叫**"织房"**——因为里面那台老纺机还在转。

**规则一句话**:诺恩三姐妹还在纺,纺的不是命,是**记性**。每个人身上绷着一根线,线的长度就是他被人记得的程度。人猝死的时候线会崩断,断头留在尸体边**三天**,必须收走;不收,线会自己往回长,死者会开始"被人想起来"——那是违规的,死人不该占活人的记性。

**行话(老人嘴里的话,新人要先学这个)**:

- **断头**:留在死者身上的那一截,泛暗金,比头发细,能像活物一样抽动;
- **回长**:不收线的后果。尸体边上开始出现认识他的人,来了想不起自己为什么来;
- **打结**:把两个死人的断头接起来,让一个人被顶替记住。违法,富人家常用;
- **领线**:把死者被记得的权利过户给活人。这个市场比毒品黑。

**价目表挂在织房墙上**:一根断线折五枚银币,**每季度调一次价**。宋迟的两千八、疗养院的三千二、他屋里那台二手笔记本,全挂在这张表上。涨价那季度,织房里没人说话;跌价那季度,有人开始偷线。

**代价**:收线上手之前,得先把自己的记性放进去剪——用一次,忘一点。宋迟已经忘了他母亲的声音,现在只记得她说话时爱用左手压住桌角。

## 三、开篇这一幕(定调)

夜里十一点半,织房打来电话:城南桂花里 4 号楼,一具"心衰",让他去收线。他是替补,上去的是老周,老周今天请假,电话才落到他头上。

他骑电动车过去,雨没停。进门,尸体坐在沙发上,毛衣领口歪着,上半身没有脸,左手却很干净,五根指头关节分明——线缠在那只手上。

他掏出剪子,手抖,刃口对不准指甲缝。老周在电话里骂他:"你他妈量三遍再剪!上次那根你剪偏半寸,三小时后又长回去,赔了两个月工资你忘了?"

他量了三遍。剪下去。

线断了,断面缩成一个小灰团。他捏在指间,忽然觉得那团东西是温的——不像死人身上的东西。

他按流程收好,掏出本子记账:第二十根。他心里想的是这个月疗养院的单子;想的是楼下那家炸串摊今天没出摊;想的是那款游戏七月停服之后,他晚上干什么。

就在这时候,门口有人敲门。他去开门,门外站着一个四十多岁的女人,问他:"这是老陈家吗?我来看看他。"

宋迟说:这屋没人住。

女人说:那我怎么知道他今天走了。

宋迟愣了一下。他低头看手里那团灰——它刚才动了一下。

**"回长"开始了。**

他的第一反应是走。他走到楼道,掏出手机。他给老周打电话,响了两声,他挂了。他站在楼道里,听着屋里的声音(那女人在跟尸体说话,说得又轻又慢)。

然后他把手机塞回兜里,转身回了那间屋。

**为什么回来,他自己也说不清。** 也许因为那句话说到一半的时候,他听见她在喊一个名字。那个名字,是他小时候邻居家的一个孩子,那孩子六岁那年掉进江里。

## 四、剩下的照旧

- **第一卷四幕**:手艺(1–25)→ 打结(26–50)→ 领线(51–75)→ 价目表(76–100),结构不变;
- **中段**:领线黑市浮上来,富人买记性、穷人卖被记得的权利换钱,主角从"缺钱"变成"他很快也要被卖";
- **后段**:织房上面还有一层——三台纺机,其中一台早就停了。她们的规矩不是神话,是行政:收线、报废、调价、存档;
- **结尾**:他没能改写纺线,但他可以在那张表上把某个人的名字从"已报废"划到"存续"。划一次,忘一件事。最后一次,他忘了自己是干什么的。

## 五、这一版和上一版的区别

| | 上一版 | 这一版 |
|---|---|---|
| 主角 | 手艺不稳的临时工,靠"手抖"表现无能 | 路明非式的废:自我评价极低、嘴碎、想跑、有个不敢说话的人;他的无能是**性格**,不是技能 |
| 他的"特殊" | 记得住别人被剪掉的部分(像天赋) | 同上,但**不是天赋,是折磨**:他因此睡不好、被当成有病 |
| 他为什么回来 | 因为是主角必须回来 | **他自己也说不清**,只知道那声名字戳到了他 |
| 城市 | 西式人名的现代城市 | 中文语境:临江市、老城区筒子楼、桂花里、织房、炸串摊 |
| 神话用法 | 北欧神话作为设定 | 北欧规则作为**行政与行规**,不提神,只留表和价 |
