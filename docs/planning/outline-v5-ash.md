# 大纲 v5:白蜡树(龙族骨架 · 北欧 · 腹黑废柴)

> 用户定的方向:现代都市 + 秘密学院/组织 + 神话血脉(龙族那种);口味是"有超自然但不脏不俗 + 暗面可以黑深残 + 要燃要亮要少年感";主角在路明非式废之上**再加一层腹黑**。

---

## 一、世界:表面一座城,底下九层旧账

**临江市**,现代城市,该有的都有(地铁、外卖、直播、学区房)。

**底下的那一层**:诸神黄昏没打完——**打了一半,停了**。阿萨神族赢了上半场,却发现自己也快死光了,于是和人类里最会算账的那批人签了一份东西,史称**《灰约》**:神族退到世界树的背面去养伤,九界的裂缝由人类**代为看守**,换来的是神族不再插手人间,也不许任何人重启那场仗。

守住这份约的,是一个不提名字的组织——行里叫**「灰袍」**(取自那个穿灰斗篷、独眼、到处流浪问人"你愿意拿一只眼睛换什么"的老家伙)。对外它挂着"白蜡树校友会"的牌子。

**「白蜡树学院」**是灰袍办的学校。明面上是城郊一所民办寄宿制高中,学费全免、包吃住、招生简章上写着"面向成绩不理想但身体条件良好的学生"——宋迟就是被这张简章骗过去的。

学院教的不是数理化,是**怎么带着一身神族的血活到毕业**。

### 血脉(等级即歧视链)

| 档 | 名称 | 特征 |
|---|---|---|
| 一档 | **阿萨血** | 雷、战、智、死四支;灰袍正式成员几乎都出在这一档 |
| 二档 | **华纳血** | 自然、丰饶、看见未来(看得见但改不动) |
| 三档 | **巨人血**(约顿) | 力量大、活得久、脾气坏;灰袍的假想敌 |
| 四档 | **混血/稀血** | 什么都能沾一点,什么都不成;学院里人数最多,地位最低 |
| 不入档 | **洛基血** | 不在谱上。上一次出现是黄昏的推手,灰袍的档案里这栏写着"见即报" |

**力量三条路**(都带代价,不搞升级打怪那套):

- **刻符**:把符文刻在身上或兵器上,借用一支血脉的性子。代价是**性格被那支血脉拖走一点**(刻雷的人会越来越急,刻死者会越来越冷);
- **真名**:知道一个东西的真名,就能叫住它、束缚它。代价是**你的名字也会被别人知道**;
- **契约**:和战死者的残念签,借它的技艺与经验。代价是**你会越来越想它**,想多了,它就住进来。

### 冲突

**巨人后裔**没签《灰约》,他们认为那份约是被人骗着签的。他们做的事叫**"解扣"**:把世界树背面的伤撕开,让黄昏接着打完。灰袍管这叫恐怖活动,巨人管这叫回家。

## 二、主角:宋迟,18 岁,复读失败,腹黑

**出身**:父亲早年跑了,母亲在小区做保洁,一个月两千二。他复读一年,差本科线十七分。家里拿不出第二年的复读费,他也不想再让母亲掏钱——**白蜡树学院的简章是他自己在垃圾站捡的**(来源不明,这一条后面有用)。

**他的"废"(路明非那一层)**:
- 自我评价极低,遇事先想"这跟我没关系";
- 嘴碎,一点小事能贫;被人夸会不知所措;
- 心里有个人——初中同桌**温知夏**,后来考去市重点,他三年没敢发一条消息;
- 廉价止血:一款快要停服的老网游,打到关服;泡面;楼下五块钱两串的炸串;
- 没野心:他不想当英雄,只想"活得像个人"。

**他的腹黑(这一层是新的,也是这版最要紧的变化)**:

| 表现 | 底下的算盘 |
|---|---|
| 被人点名挑战,他先认怂、往后退 | 退的同时在数对方几秒钟眨一次眼、哪只手插兜、鞋带松没松 |
| 当众说"我不行,你们打" | 心里已经把在场四个人谁跟谁有仇捋完了 |
| 从不主动挑事 | 只递话、只给机会,让别人替他动手 |
| 被欺负了不还手,还笑 | 记账。他的账记得极清:谁欠他一次、哪次、什么场合 |
| 看着老实,爱装傻 | "啊?还有这规矩?" —— 他比谁都早把规矩看明白了 |
| 关键时候他下手最准 | 不是热血上头,是**算准了才动**——这也是他比路明非更冷的地方 |

**底线**:不害无辜、不卖朋友、不拿母亲的事做筹码。这三条他自己也知道有点蠢,但他不肯改。

**他的血脉**:洛基血。他手背上那枚胎记是**未成形的符**——也就是说,他不是"还没觉醒",他是**谱上不该有的一支**。灰袍的档案上,他那栏写着"见即报";而灰袍之所以没当场处理他,是因为有人把那份报告压了下来(谁压的,是第一卷的问题)。

## 三、第一卷:入学(约 100 章)

**开篇**:他坐了三小时公交到城郊,校车是一辆喷着"白蜡树中学"的旧中巴,司机是个没有左眼的老头(灰袍外勤)。车上另外六个新生,三个在睡觉,两个在打牌,一个女生从上车起就在看他——**看他手背**。

**第一幕(1–25)入学与分级**:体检(采血、照骨、测血脉)、分档(他测出"不入档",被丢进混血班)、军训式的体能课(他倒数第一,而且他用腹黑把倒数第二推给了别人)。他在这里认识:嘴毒的室友、混子朋友、以及那个在车上看他手背的女生**韩青**(阿萨血·死支,二档,冷)。

**第二幕(26–50)规则**:学院的规矩比课堂多——不许夜里出宿舍楼、不许靠近后山、不许在校园里叫任何人的全名。他犯了第一条(为了打游戏翻窗去机房),撞见了不该看的东西:后山有人在做"解扣"的试验,他看到了一个不该有脸的影子。他这回没跑——**因为他认出那个影子身上的东西,是他妈常年擦的那块抹布的图案**(这条线后面会牵出他母亲的来历)。

**第三幕(51–75)实战课与第一次出校**:学院组织"见习"(真刀真枪处理校外的一处裂缝)。他被分在最差的组,靠腹黑让同组的天才去当先锋,自己在后面记账。结果出了岔子:组里两个人重伤,他第一次**主动刻符**(在同伴的血里刻的),符是歪的,但成了。代价:他连着三天做同一个梦,梦里有人在说"你终于肯用我了"。

**第四幕(76–100)卷末**:韩青查到他手背那枚胎记不是胎记,是**符**;灰袍内部有人要按档案规定"见即报",有人压着不报。第一卷收在他做了个决定:他没有向任何人坦白自己听见了那个梦,而是**把梦里那个人说的话记进了自己的账本**——因为他已经算清楚:在这所学校里,一个"不入档"的人是没人管的,而一个"洛基血"的人,是所有人都会管的。他选择先当那个没人管的。

---

## 四、往下怎么长

- **第二卷**:他知道自己是什么之后,开始**用它**——不是为了变强,而是为了在这套体系里活下去。他发现洛基血真正的用处不是骗人,是**换名字**:他能替别人挡档案、改记录、把黑锅甩给该背的人。学院开始有人找他办这种事。
- **第三卷**:巨人那边来找他(他们也需要一个"不在谱上"的人来解扣),灰袍开始怀疑他。他两头拿好处,两头都不站,直到他的母亲出事——《灰约》的另一半条文浮出来:**神族不插手人间,但他们的债在人间的孩子身上收**。
- **第四卷**:诸神黄昏的下半场。灰袍、巨人、以及世界树背面那些"养伤的老家伙"三方摊牌;宋迟是唯一一个谁都不信、谁都骗过、也谁都不欠的人。
- **第五卷**:他不参战。他做的是**把《灰约》补上一条**:神族与巨人的账,不许由人间的孩子代偿。签这一条需要他拿真名去换——他要先把名字交出去,才有人肯在上面签字。

## 五、这一版凭什么不一样

| | 常见套路 | 这一版 |
|---|---|---|
| 主角进学院 | 被选中/天赋异禀 | 自己从垃圾站捡的简章,为了省复读费 |
| 主角的血脉 | 最强的那种,后期觉醒打脸 | **洛基血**:谱上不该有的一支,灰袍的规定是"见即报"。他最大的优势是**没人管他** |
| 主角的废 | 自卑+善良 | 自卑+善良**+腹黑**:认怂是战术,装傻是情报,记账是习惯 |
| 力量成长 | 升级、打怪、变强 | 三条路都有**人格代价**(刻符改性格、真名泄自己、契约被人住进来) |
| 结局 | 屠神/牺牲 | 不参战,只**补一条合约条文**,代价是交出真名 |

## 六、还要你定两件事

1. **血脉路线对不对**:洛基血(骗、变、换名字)+ "不该存在的一支" + 灰袍要"见即报"——这条设定合不合你的口味?
2. **学院气质**:现在这版是"民办寄宿高中 + 准军事化 + 免费管吃住"的路子(偏《龙族》卡塞尔的那种封闭感)。要不要更贵族化一点(精英学院、少爷小姐、鄙视链更明显)?
