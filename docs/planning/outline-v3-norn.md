# 大纲 v3:一条线、一张价目表、一个收线的差事

## 一、先说这份大纲凭什么这么写

三个可查的事实,决定了方向:

1. **纯西幻已经沉沦**。起点奇幻推荐总榜前排是《盘龙》(2009)、《放开那个女巫》(2016)、《琴帝》——新书几乎挤不进去。写精灵矮人魔法学院,等于开局就站在退潮的海滩上。
2. **"都市 + 真实行当 + 怪谈"正在赢**。纯滴小龙的《捞尸人》(黄河捞尸人)2025 年蝉联月票榜首、652 万字、均订破十万,实体书出版;它火的原因不是鬼画得多吓人,而是**把恐怖扎进一个具体职业的规矩里**——"红衣竖尸捞不得"这一句祖训,比十页世界观更抓人。
3. **废柴流死了**。读者原话是"又是废柴流,不看";这两年大热作品里基本见不到"天才跌落→逆袭打脸"。**但"底层主角"没死**——《捞尸人》的主角李追远是个十岁被送到外公家的孩子,不是天选之子。读者烦的不是穷主角,是**穷得没有具体理由**。

至于北欧神话:直接写诸神是小众,而且套路固定(穿越成神、屠神、领主种田)。**正确用法是把它降成世界的底层规则**——像《捞尸人》的"走江规则"那样:不解释神话,只留下它的规矩和价码。

## 二、世界:一条规则,一张价目表,一个局

**规则一句话**:诺恩三姐妹还在纺,但她们纺的不是命,是**记性**。

每个人身上都绷着一根线,线的长度就是他"被人记得"的程度。人猝死的时候线会崩断,断头会留在尸体身边**三天**。三天内必须收走——不收,那根断线会自己往回长,死者会开始"被人想起来",而那是违规的:死人不该再占活人的记性。

**编织局**就是干这个的。它挂在市政底下,公文里叫"市属殡葬事务第三处",编制十九个人,管着全城所有猝死。它有自己的一套行话和设备:

- **断头**:线崩断时留在死者身上的那一截,泛暗金色,比头发细,能像活物一样抽动;
- **回长**:不收线导致的后果。尸体边上会开始出现认识他的人,想不起为什么来;
- **打结**:把两个死人的断头接在一起,让一个人被"顶替"记住。违法,但需求很大——富人家常用;
- **领线**:把死者的线头交给活人保管,等于把"被记得"的权利过户。这个市场比毒品黑。

**价目表**是这套设定最要紧的东西:一根断线折**五枚银币**,局里按季度调价。主角的收入、他的房租、他母亲的住院费,全挂在这张表上。**读者要的不是境界突破,是这个月能不能凑够钱。**

代价也必须是真的:收线上手之前,得先把自己的记性放进去剪——用一次,忘一点。**主角已经忘了他母亲的声音,只剩下她说哪句话时的手势。**

## 三、主角:他的"废"要有具体理由

**维恩·卡尔森,23 岁。**

白天在殡仪馆给遗体化妆,按夜结算,一夜三十枚铜子;夜里替编织局收断线,一根五枚银币。他住城南铁皮搭的隔间,入冬漏风,上个月刚花三百块重做了防水层。

他的"废"是**具体**的,不靠自我贬低来表现:

- 他**没有资格**——编制十九个人,他是第十九个的替补,一个只在有人请假时才被叫去的临时工;
- 他**手抖**——第一夜收线时剪偏了半寸,那根线回长了三小时,他把一具尸体"复活"成了邻居口中的传闻,赔了两个月工钱;
- 他**算不清账**——他记不住钱,因为他把记性都用在记别人身上了;
- 他**怂**——遇到事第一反应是走,第二反应是假装没看见,第三反应才是硬着头皮进去。他的幽默是防御,不是潇洒。

他唯一算本事的东西:**他记得住别人被"剪掉"的部分**。别人收线会忘,他忘了还会梦到。所以他脑子是个垃圾桶,里面全是死人不该被记住的事。

读者不会因为他穷而厌烦他,因为他每一夜都在为一件具体的事犯愁:这个月的住院费、那根剪偏的线会不会被人发现。

## 四、第一卷:他要收的第二十根线(约 100 章)

**开场不是一个异象,是一笔账。** 他已经收了十九根,单子压在枕头底下——母亲住在城东那家医院,这个月已经拖了一周。第二十根在城南一间没人住的老房子,登记死因是"心衰"。

他去了。尸体没有脸,毛衣领口歪着,左手却干干净净、关节分明。线就缠在那只手上。

第一幕(1–25 章):**手艺**。他怎么进门、怎么开工具袋、怎么和尸体打交道、怎么算钱。第一夜他剪错了一次,后果是那具尸体被三个人"想起来",他赔了钱、被局里记过。读者在这里认识行规,也认识他的手艺有多不稳。

第二幕(26–50 章):**打结**。一桩富人委托找上他——把死在国外的儿子和一个刚死的流浪汉"打结",让家里人记住他。价格高到他母亲的住院费一次性结清。他接了。但打结之后,那个流浪汉的线没有安静,反而开始往回长。他发现有人在这一单里做了别的手脚:被打结的不是两个人,是三个。

第三幕(51–75 章):**领线**。他去查第三根线是谁的,查到自己父亲:二十年前死在城北水厂,登记为"溺毙",线没有收。也就是说,父亲一直被人记得——记得他的人是谁,靠什么记得,这是全书的问题第一次露头。同时他发现自己那根被别人保管的线,长度不对:他被人记得的程度,和他该有的长度不一样。有人一直替他补线。

第四幕(76–100 章):**价目表**。局里季度调价,断线从五枚银币跌到三枚,他这一行的人开始另找出路:偷线、卖线、替人打结。第一卷收在他做了一件违背行规的事——他没有上缴一根线,而是自己留着。因为他要留下一个人的记性,那个人,是唯一记得他母亲声音的人。

## 五、往后怎么长(不写"第几卷",只写长势)

**中段**:领线的黑市浮上来。富人要买记性,穷人要卖掉自己被记得的权利换钱——这是一条能长几十万字的产业链,不需要新地图,只需要新的雇主和新的尸体。主角的处境从"缺钱"变成"他要在这条链上做一个选择":他自己很快也会被卖。

**后段**:父亲那条没收的线,牵出"谁有权决定一个人被记得"这个问题——编织局上面还有一层:三个人,三台纺机,其中一台早就停了。她们的规矩不是神话,是**行政**——收线、报废、调价、存档,全是流程。主角最后要对抗的不是神,是流程:一张表,一支笔,一个签字的空位。

**结尾**:他手上留着一堆本该上缴的线。他没能改写纺线,但他可以在那张表上做一件事——把某个人的名字从"已报废"栏划到"存续"栏。划一次,他忘一件事。最后一次,他忘了自己是干什么的。

## 六、为什么这样能写到百万字

不用"不断开新地图",靠四件事滚动:

- **价目表波动**:每次调价都改变这一行的生计,这是天然的事件发生器(涨价→抢单,跌价→黑市);
- **雇主与尸体**:每几章一具尸体、一个雇主、一件委托——单元剧结构撑得住长连载,像《捞尸人》那样;
- **他自己在忘**:主角的记忆是消耗品,读者能看见东西在减少,这是长篇里最稀缺的"不可逆"张力;
- **记性的分配**:谁该被记得、谁该被忘、谁付钱买——这是能一直问下去的问题,而且每一阶段的答案都不同。

## 八、需要你定的三件事

1. **书名**:《收线人》《织机声》《断头线》《五枚银币》——或者等正文出来再定;
2. **"废"的程度**:现在这版是"临时工 + 手抖 + 记不住钱",要更怂一点还是更硬一点?
3. **城市**:西式人名的现代城市(像《余烬之铳》那种),还是**中文语境的现代城市 + 北欧规则**(像《捞尸人》那样本土行当)?这一条决定全书的语感。
