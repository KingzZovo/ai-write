# 自然叙事反机械化流程

> 来源：第五章《封灯录》多轮生成质量闭环暴露的问题。本文档抽象为跨章节、跨项目可复用流程，不绑定具体剧情。

## 1. 适用目标

用于在生成前识别并抑制 AI 小说文本中的机器痕迹，重点治理四类结构性问题：

1. 对话像剧本大纲。
2. 动作像物理演算。
3. 叙事像舞台说明。
4. 线索像游戏道具。

本流程属于 generation-before 诊断与提示注入，不作为后置硬门禁或 `needs_repair` 主流程。

## 2. 四类通用诊断

### 2.1 对话对称症

症状：
- 连续一问一答。
- 对话轮次规整，句长接近。
- 角色过度配合交代信息。
- 缺少迟疑、抢白、打断、沉默、误解、答非所问。

生成前约束：
- 禁止连续三次以上规整的一问一答。
- 紧张、逼问、威胁场景中，被问方必须出现至少一种失真表达：迟疑、转移话题、答非所问、被环境音打断、情绪失控、短促反问。
- 允许一方不回答问题，允许信息被遮挡、误解或延迟给出。

### 2.2 动作演算症

症状：
- 高频使用单字动词制造冷硬感，如“送、探、砸、磕、挑、压、扣、翻”等。
- 动作被拆成细碎轨迹。
- 人物像执行机械指令，而不是在压力中做选择。

生成前约束：
- 限制同一段落中单字动词密度。
- 动作描写优先写意图、结果、环境破坏、旁人反应、局势变化。
- 禁止把身体轨迹当作主要叙事内容。

### 2.3 舞台说明症

症状：
- 固定出现“人物 + 微动作 + 台词”。
- 每句台词前强行配一个动作。
- 动作与台词没有因果，只是舞台调度。

生成前约束：
- 台词可以直接抛出，不必每次前置动作。
- 环境变化和人物反应应穿插在对话段落内部或台词之后。
- 同一对话段内，禁止连续多次使用“动作 + 台词”的刻板开场。

### 2.4 道具解说症

症状：
- 物品像游戏调查点，一出现就被角色说明用途。
- 人物在不合理视线、光线、距离、心理状态下精准识别线索。
- 角色像法医报告一样直接念结论。

生成前约束：
- 证物发现必须符合视线、光线、距离、气味、触感、记忆条件。
- 暗处、混乱、压迫场景中，只允许有限判断和不确定表达。
- 线索呈现顺序应为：异常反应 → 感官触发 → 不确定判断 → 有限结论。

## 3. 生成前处理流程

### Step A：先做结构诊断，不只查词

生成前检查：
- 是否有连续一问一答。
- 是否同一段内单字动词密集。
- 是否每句台词前都有动作。
- 是否证物被直接解说。
- 是否短句连发来自“动作切片”。

### Step B：按四类问题贴标签

输出内部标签：
- `dialogue_symmetry_risk`
- `motion_calculation_risk`
- `stage_direction_risk`
- `game_item_clue_risk`

这些标签只用于生成前提示，不作为后置硬门禁。

### Step C：生成时按替代写法执行

替代策略：
- 对话：用打断、沉默、反问、情绪宣泄、答非所问打破对称。
- 动作：用结果和环境反应替代轨迹演算。
- 台词：避免每句前置动作，允许台词直接切入。
- 线索：用感官与认知过程承载发现，不直接念报告。

### Step D：输出前自检

输出前只做内部自检：
- 连续短句是否超过目标。
- 禁用词和微观刻度词是否残留。
- 是否存在连续三轮以上对称问答。
- 是否存在多段“动作 + 台词”重复结构。
- 是否有超视距、超光线条件的道具解说。

## 4. Prompt 模块建议

模块名：`natural_narrative_anti_mechanical_flow`

建议写入生成前提示：

- 打破对话对称：禁止连续三次以上“一问一答”短句交锋；紧张场景必须出现迟疑、打断、反问、沉默、抢白或答非所问。
- 剥离机械前置动作：禁止滥用“动作 + 台词”；台词可直接抛出，环境变化和人物反应穿插在段落内部。
- 限制单字动词密度：同一段落不得密集堆砌“磕、砸、送、探、挑”等动作词；动作只写必要结果。
- 去游戏化线索展示：证物发现必须符合视线、光线、距离和感官逻辑；禁止角色在不合理条件下直接念出结论。
- 保持已有底线：微观刻度词、硬拼名词、解释堆积、长引语和段落风险仍需控制。

## 5. 与现有机械指标的关系

现有指标继续保留：
- 禁用拼接。
- 微观刻度词。
- 短句连发。
- 动作轨迹词。
- 解释堆积。
- 长引语。
- 段落风险。

新增自然度指标建议：
- 对话对称度。
- 动作前置率。
- 单字动词密度。
- 线索解说化程度。
- 证物发现合理性。
