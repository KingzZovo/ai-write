# 作者关联伏笔正文来源（2026-10-08）

源码实现与离线验证完成，尚未执行迁移或部署。运行环境最后核实的隔离版本仍为 `c4b4a4b`，不能把本轮能力当作已上线。

## 已核实的问题

现有 `inspect_foreshadow_sources` 只读取作者接受的模型线索候选。手工创建、旧计划副本或编辑描述后的伏笔，即使作者能够指出正文原句，也没有重新建立关联的入口；这些记录会一直排除在自动写作上下文之外。

## 实现

1. 新增独立的作者正文关联记录，保留请求编号、前一关联、登记内容版本、完整正文/章节位置摘要、逐字引用、作者与时间。历史关联不覆盖；最新的解除或过期关联不能回退到旧证明。旧裸章号不猜测转换，也不修改原伏笔或图谱状态。
2. 提供作品范围内的章节检索、完整正文预览、关联/解除及历史读取入口。提交前在短事务重验作品、章节、伏笔和前一关联；重复请求只返回原回执。引用必须在当前全文中唯一命中，无法定位时要求作者扩大引用。
3. 来源检查和后续写作读取采用当前作者关联的明确章节位置；没有人工关联的记录继续沿用既有候选登记证据。新增作者界面，保存失败保留输入，切换作品/章节后迟到响应不覆盖新状态。
4. 章节标题、稿件状态和回应计划不改变原句身份；正文、位置、登记描述或类型变化使关联失效。浏览器选区从规范化的LF/UTF-16位置映射回原保存文本，保留CRLF、多行和emoji，服务端记录Python字符偏移。
5. 章节或伏笔删除后保留关联记录；已知伏笔ID仍可读取历史，已打开的表单可继续查看。伏笔已删时禁止新写入。作品永久删除才清理历史；迁移降级遇到已有记录时拒绝丢弃。新增迁移 `a1001943`，前置 `a1001942`。
