# 改写停止后的任务终态与候选读取

## 问题

后台改写循环遇到局部未落实或整章失败时仅break，仍会执行后续quality gate、正式章节写回、摘要和认知提取。停止修订的候选可能被第二条改写路径继续改动；旧needs_repair错误还把供应商问题描述成场景规划问题。

## 行为

本轮引入局部revision_stop_reason。局部未可靠落实、整章异常（含明确供应商截断）或空正文统一在循环后直接保存任务needs_review并return。任务result_text/progress_text逐字保留current_text，包括空白与段落；不采用失败改写片段，不调用清洗器、不写正式章节、不进入后续质量改写与记忆提取。已有任务参数保留，中文错误说明区分失败类别。此结论只针对停止分支之后；此前生成链路已有写入不在本次改动内。

任务面板给needs_review提供展开查看入口。列表接口只给末尾200字，因此展开后读取`GET /api/generate/async/{task_id}`的完整result_text，必要时使用完整progress_text。列表片段不用于全文展示。迟到读取在收起/任务变更后忽略；错误明确显示，可收起重试。不自动把候选应用到章节。

## 验证与复核

41项后端离线/AST分支测试通过，覆盖四种停止原因、原文逐字保留、章节对象不变、return先于后续质量门禁及既有改写重试/定点路径。16项前端测试和tsc通过，包含展开前不请求、展开后读完整任务结果而非200字尾部。

shadow-mind采用本地两轮复核：状态流检查定位break后继续改写的问题并确认新return位置；用户可见性检查发现列表200字截断并改为按需读取详情。平台无可靠只读子代理隔离，未启动子代理。代码diff检查通过。

## 限制

不是完整Celery/数据库/浏览器联动验收；任务详情读取失败与关闭期间迟到响应虽有实现防护，尚无新增故障交互测试。候选采用仍由作者复核，停止不等于本章文学合格。SSE对应停止后处理、非停止路径的二次polish以及前序生成保存继续待检查。未新增迁移、未部署，迁移头仍a1001934。
