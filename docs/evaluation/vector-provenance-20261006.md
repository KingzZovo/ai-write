# 向量记忆的稿件来源校验

## 完成的调用链

新增 `vector_provenance.filter_current_memory`。章节摘要向量携带稳定章节ID和summary_source_hash；正文片段携带章节ID及完整来源正文SHA256。正常摘要投影、RAG重建及正文片段回填都写入这些字段。

ContextPack与旧HierarchicalMemory的项目历史召回，在注入前按ID批量查询当前PG记录。要求作品/卷/卷内章号/全书章号匹配、状态completed、章号早于当前目标。摘要还必须与PG当前摘要完全相同且来源指纹有效；片段必须与当前完整正文哈希以及按相同规则重新切分的对应片段完全一致。读取不依赖ORM身份缓存，不自动flush。缺失、删除、改稿、改序、待审或查询失败均不注入。

压缩器每100条候选验证当前来源，仅压缩有效摘要；每条新压缩记忆保存完整来源凭据列表及数量、全书起止章号。召回时逐项核查，凭据缺失、重复章节、数量/范围不符或任一来源失效，都不注入。来源检查不证明模型压缩内容本身无幻觉。

候选召回扩大至摘要25条、片段15条，验证后仍分别最多注入5条/3条，避免前几个旧向量把较低排名的有效记忆挤出窗口。单次来源核查最多200个章节；不是无界全书加载。

Agent备用search_memory也接入分片/旧集合解析、持久化当前章边界和同一来源校验，客户端在finally关闭。run_tool以任务传入的作品ID覆盖模型参数；search_memory的章节ID也由任务上下文固定，缺少可信上下文不检索。其他人物工具的历史状态语义不由这项修复宣称完成。
