# 记忆卡来源、保留与回读语义

## 修复

旧记忆卡写入根据全书 character_appearances 缓存决定 first_appearance；旧标签永久保留，多个标签可能超过配置上限，并挤掉近期有效片段。回读又只取一个 first_appearance，把其他同标签有效片段全部排除。提示中的“初登场”“已多章未出场”也超出了精确字符串匹配能证明的范围。

本批改动：

- 写入时从当前章之前的有效正文提及记录判断是否已有早期记录，使用上一批统一历史读取，不再依赖无来源全书缓存。
- 每次为涉及人物执行保留策略前，通过既有来源校验核对章节身份、项目、状态、版本、唯一全书章号以及逐字摘录。失效和未知来源卡片不能占用保留名额。
- 正数容量上限下保留一个最早有效片段，再保留近期片段；旧 first_appearance 标签只参与同章排序，不再无限保留。cap<=0 保持原有不限制有效卡片数量的含义，来源校验仍执行。
- 回读从已校验卡片中选一个较早片段及至多两个近期片段，不再把其他 first_appearance 卡片全部忽略。
- 保留数据库标签兼容性，提示展示改为“早期片段”；明确提及不等于人物在场或知情，不推断首次登场。正文原文不修改。

## 独立复核与边界

按 shadow-mind 的无可信只读隔离环境回退条款进行本地独立复核：核对实际版本化投影调用仍在项目租约和当前章节来源锁内；记忆卡事务错误继续传播用于重放；校验发生在容量筛选之前；读取端仍逐条验证来源与摘录，没有因标签保留而绕过。

不新增迁移，不批量删除历史正文。卡片属于可重建投影，失效卡片清理仅在本次写入涉及的人物范围内进行，读取端仍排除其他失效卡片。历史全量重建没有在本批执行；正数容量限制仍意味着不是保存所有历史片段。

当前人物名与别名仍是设定，不是逐章身份版本。精确匹配不能理解代词、同名或人物实际到场，故不作为剧情事实。认知账本仍需逐章来源、时序及提取链路改造，相关章的状态/伏笔信号也仍需复核。

本批源码尚未装入 ARM 隔离镜像或生产；不宣称已完成文学或全书生成验收。
