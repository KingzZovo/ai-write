状态：代码、离线回归和冻结本地复核已完成。基线提交 `e6849f2`；迁移 `a1001944` 尚未在真实 PostgreSQL 执行，未部署。

## 已核实的问题

`cached_discovery` 按完整保存稿与章节位置复用第一次成功结果，包括空结果。修改模型或提示词后，普通核查仍复用该清单；直接删除缓存会损失作者决定或重复登记。因此需要显式重扫及完整历史。

## 本轮计划与完成范围

1. 新增扫描轮次、每轮候选成员及固定请求回执。普通核查复用同稿最新成功扫描；显式重扫使用任务来源 revision，任务重试沿用同轮。章节删除仍保留请求/扫描证据，作品永久删除清理。
2. 同稿下仅在描述、类型、逐字引文及位置完全相同时复用候选 ID 和首次作者决定；这些字段变化时形成新候选。本轮 reason 独立记录，不把旧决定描述成对新说明的批准。新扫描不覆盖旧清单。
3. 请求 UUID 与项目、章节、正文摘要、重扫模式固定绑定。响应丢失重试返回原任务；活动重扫复用，活动普通核查期间明确拒绝新重扫。回执和新任务同事务提交。
4. 界面增加“重新识别线索”、会话内原请求重试、按轮次查看及成功空结果说明；保留编辑切换和迟到响应保护。普通兑现核查继续原有去重语义，本轮不宣称其已支持多版本解释。
5. 补扫描、空结果、作者决定不重放、请求重放/冲突、失败回滚/取消、来源变化、旧执行令牌、历史留存和 UI 用例；真实 PG 迁移/锁竞争仅编写待运行测试。
6. 运行重点测试、全目录离线后端、完整前端及生产构建；冻结代码做正确性和完成性两轮本地复核，修复具体问题并同步四份仓库文档。

## 实现

- `foreshadow_discovery_runs.scan_revision` 将不同轮次与来源摘要分开；普通任务取同稿最近成功扫描，显式重扫使用该任务的 `source_revision`。任务记录实际使用的 `discovery_run_id`，不把缺失结果当作空清单。
- `foreshadow_discovery_run_items` 保存每轮完整候选顺序和本轮说明。精确相同候选共享原 `ForeshadowDiscovery`，作者已忽略、已登记、后续修改或已删除的登记均不重放。
- `foreshadow_review_requests` 在同一事务内绑定请求与原任务；章节删除后仍可读原请求的不可用状态，不能重建旧任务。作品软删除阻止新请求，永久删除清理请求及扫描历史。
- 新 `/discovery-runs` 历史接口及 `/discoveries?status=all&run_id=...` 按轮次读取；两条路径均限定作品。历史和缓存共用成员完整性校验，数量、位置、说明或成员来源异常明确为不可核验。
- `ForeshadowReviewJobs` 增加显式重扫，`ForeshadowDiscoveryHistory` 支持按当前章节查看历史与成功空结果；候选界面区分本轮说明、首次说明及作者处理状态。
- `foreshadowReviewRequests.ts` 按逐字请求材料保存每份未确认请求。恢复旧稿后重试仍用原编号，迟到响应仅清理自身记录。明确的 409/422 拒绝清理该请求；结果不明时保留。会话存储写入失败时，当前页面内存优先于旧存储值。

## 架构与边界

- 继续使用现有 FastAPI 服务层、SQLAlchemy 事务、Registry 模型调用与 Celery 恢复，不增加并行写作链。
- `source_sha256` 仍是完整正文及位置快照的摘要，不混入扫描 revision。
- 新成员表保存每轮清单及本轮说明，原候选表继续拥有作者决定和登记 ID；不以同义词或模型评分自动合并。
- 请求回执独立于会随章节删除的 Job；新建请求锁先于来源锁，worker 不反向取得请求锁。请求仅在已提交回执存在时允许绕过当前正文核查以读取历史结果。
- 模型名称只记录返回结果携带的调用标识，不在调用后重新读取配置冒充该次模型或 Prompt 版本；CPA 上游实际供应者仍须实测确认。
- 已核对 `GenerationResult.model` 是成功供应商调用所用的模型参数，包含路由回退后的名称；不是 CPA 上游模型身份的独立证明。未新增 Prompt 版本凭据，不推测旧记录的模型名。
- 核查任务仍同时执行既有兑现核查，其建议继续按原来源去重；本轮只新增线索识别的多轮清单。失败或取消后，未提交的模型结果仍可能在原任务重试时重新调用；固定请求解决 HTTP 提交重放，不承诺供应商调用在崩溃后只计费一次。
- 网络、运行服务、PG、Neo4j 与 CPA 当前连接受限，本轮不重试连接。使用既有私有测试入口，不读取其脚本、环境或凭据。
- 工程验证不证明中文正文合格；默认模型不切换，连续章节文学验收与部署仍在总计划待办中。
