# 后台评审与稿件内容绑定

后台评审此前只存评分/意见，无法核对模型看的是否为当前正文。新增evaluation_source：模型前对章节ID、完整正文和细纲生成带version=1的SHA256来源标记，随EvaluateTask.result_json保存。不额外保存正文副本，不需要迁移。

GET任务状态读取当前章节，返回source_status=unchanged/changed/unknown；不修改历史评审，不把缺少或格式异常的标记推断为当前。正文空白变化可检测，细纲JSON键顺序变化不构成内容变化。章节身份或细纲变化、带标记的章节已删除均为changed。

面板仍展示历史评分和意见，但明确标注已改稿、来源未知或“本次读取核对：正文与细纲和评审时一致。其他设定仍需核查。”未声称模型意见正确、其他上下文一致或用户尚未保存的编辑已经评审。

验证：55项后端离线回归、10项前端组件测试及tsc通过。新增9项来源/任务读取测试、1项真实后台函数的改稿期间评审替身测试，以及3项界面状态标记测试。5文件AST与git diff --check通过。来源标签只证明内容身份，不作为ChapterAcceptance门槛。

按shadow-mind无可靠只读隔离回退，冻结代码后本地复核模型前快照、无正文覆盖、读取核对、旧记录兼容与文案边界，未发现新增具体问题。新测试以会话替身执行任务/读取函数，未宣称真实PG事务集成通过。

剩余：自动生成的ChapterEvaluation、同步手动评审和旧后台记录没有本批标记，仍显示unknown；邻章、设定、风格和作者要求不在此摘要范围。页面完成加载后不会实时监视同章每次保存，用户改稿后仍需刷新/重评；文案刻意限定读取时。任务执行互斥、全来源快照、历史要求追踪、真实数据库/浏览器/模型与部署验收仍待完成。
