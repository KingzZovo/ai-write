# 大纲计划兑现不再改写为已兑现

日期：2026-10-08。未部署。

来源审计发现 foreshadows 只保留 lifecycle/neo4j 等来源类型，没有稳定的来源章节或大纲ID，旧章号无法一律安全迁移。同时，卷纲/章纲保存会将 foreshadows_resolved 描述前缀用于 ILIKE UPDATE，把匹配记录标记 resolved；这既把规划当事实，也可能命中同前缀或包含通配字符的多条伏笔。

本次移除大纲持久化中的自动兑现更新及仅供该流程使用的私有模糊更新函数。源大纲中的计划回收项保留，返回值仍为 (inserted, resolved)，其中 resolved 固定为0；新增条目的既有写入仍保留。后续只有有来源的正文证据或作者明确操作才能支持实际兑现。

49项离线测试通过。新增用例执行两种大纲持久化函数，覆盖只有回收计划/同时新增计划，验证不生成UPDATE/DELETE、不改输入大纲，并保留已有插入及提交行为。查询使用适配器，不是真实PG持久化测试。Python编译和git diff --check通过。

按shadow-mind作本地正确性/完成度复核，无可信只读隔离未启动子代理。搜索确认删除的私有更新器没有剩余应用调用点；公开持久化接口返回形状不变。

尚未完成：旧记录中错误resolved状态不能无证据批量恢复；大纲计划埋设仍沿用旧planted状态；后续需要来源ID/文本证据、明确区分计划与实际、统一新旧时间线及真实数据迁移。此修复防止继续错误确认兑现，不等于已完成伏笔生命周期工程。未部署，没有新的小说质量验收。
