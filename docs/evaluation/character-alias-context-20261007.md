# 登记别名进入人物状态召回与写作提示

日期：2026-10-07。未部署。

角色档案已有 aliases，但 CharacterCard 不携带此字段，卡片筛选只按正式姓名匹配，正文只写绰号时可能遗漏人物状态。系统与分场提示又一律禁止别名，与中文小说自然称呼冲突。

新增角色卡 aliases，在真实档案组装时保留非空字符串、去重并去掉与正式姓名相同的重复项。卡片展示正式姓名与登记称呼，匹配本章和前章材料时同时使用别名。共用别名的各人物都保留，不把字符串命中当成唯一身份解析；提示明确可能重名，需结合关系判断。取消一律禁止别名的规则，允许有档案来源或作者明确要求的称呼，仍禁止擅自改名和混同身份。名册不要求所有上下文人物出场。

57项离线回归通过：实际卡片组装（在筛选前停止以隔离后续查询）、别名独立触发召回、共享别名保留双方、实际 write_scene_stream 到注册调用的系统/用户提示内容、作者要求和流关闭回归。随后仅调整分场名册标题以与系统名册一致。Python编译和git diff --check通过。

按shadow-mind作本地正确性与完成度复核，无可信只读隔离未启动子代理。核查当前内置提示未另有禁止别名条款；数据库自定义模板未读取，可能仍有旧约束。

边界：只有登记别名参与召回；自由称谓、单字别名误召回、共用别名消歧、跨设备档案更新和实际叙事效果仍待验证。实体抽取/历史频率的别名逻辑未在本次统一，不能据此宣称全链身份系统已完善。未部署，没有新文学质量结论。
