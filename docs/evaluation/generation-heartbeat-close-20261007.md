# 章节生成API与心跳关闭

_yield_with_heartbeat已有finally取消并gather内部任务，但调用它的外层async for未显式持有关闭关系，外层在yield处关闭可能不能立即进入助手finally。章节正文及整章修订流也存在转发缺口。

章节API九处正文、修订和心跳迭代器用aclosing管理，下层关闭行为与已有服务/路由保护衔接。不改正文参数、评审决策或保存策略；大纲API与worker其他流入口不在本次范围。

71项离线测试通过：心跳在首次ping后关闭立即取消并等待内部任务，正常结果保留；AST覆盖九处入口不再直接裸转发；回归定点修订分支、章节/场景关闭、路由关闭与场景规划。首次四项定点SSE分支测试失败是执行AST片段的环境未注入aclosing，补入后全通过。AST检查只能证明转发结构，不能替代整个ASGI数据库路径测试。

按shadow-mind本地双视角复核（无可靠只读子代理隔离）：生命周期检查核对助手finally取消/gather，与外层关闭关系；状态检查确认新包裹没有扩展Exception捕获范围，取消不变成生成失败后的重试。AST/diff通过。
