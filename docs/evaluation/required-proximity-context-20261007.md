# 前文交接上下文失败不再静默继续

日期：2026-10-07。未部署。

## 发现与修复

ContextPackBuilder._build_proximity 在组装紧邻前章正文、近期摘要、本章内容和大纲、后续安排时，外层对非 SQLAlchemyError 异常只记录日志并返回。上层会继续构建并调用模型，因此缺失前文可能被误当作有效的空上下文。

现在保留原有数据库异常传播；其他逃出本层的异常转换为 RequiredContextUnavailable，保留异常原因供内部排查，公开响应固定为 context_unavailable。生成界面收到明确的中文失败提示，不能据此假设草稿保存成功。卷和章节边界验证仍保持原逻辑。

## 验证与本地复核

- 45 项离线测试通过：真实 proximity 方法配数据库适配器，分别注入 RuntimeError、TypeError、SQLAlchemyError；普通、流式和分场生成入口验证上下文失败后不调用模型/不规划场景；另覆盖预算与既有生成结束校验。
- Python 编译、git diff --check 通过。
- 按 shadow-mind 做本地正确性与完成度复核，无可信只读隔离未启动子代理。核对错误传播至直接/分场生成、SQLAlchemyError 不被降级、公开提示不泄露原始错误。

## 边界

没有真实数据库、CPA 或新小说样本；不能据离线通过宣称文学连贯性达标。已有内部可选大纲加载容错、其他上下文层的降级策略、长前章仅保留有标注尾段等仍需分别审计。此次只修复 proximity 外层异常被吞掉的问题，不声称全部必要事实均已强制获取。真实跨卷交接与长书召回验证仍待完成。
