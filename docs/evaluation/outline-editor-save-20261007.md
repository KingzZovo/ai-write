# 大纲编辑器串行保存与草稿保留

2026-10-07。当前批次尚未部署；真实PG及浏览器网络联调待完成。

## 改动

- `OutlineEditor`按项目与目标ID建立独立编辑会话。旧会话的请求返回不更新新页面或触发父组件缓存回调；卸载清理定时器。
- 自动/按钮/Ctrl-S保存串行执行，使用当前最新输入及最近成功返回的结构快照；请求期间继续输入的文字保留，成功后再排队保存新稿。失败清理自动重试，作者可核对后手动重试。
- 服务端必须返回有效content_json/outline_json才能显示保存成功。书纲/卷纲提交expected_content_json；章节提交新增expected_outline_json，在行锁内比较，过期返回409，force不能绕过，标题/正文等字段在冲突前不变。
- 纯JSON细纲的编辑按对象解析保存，不再把编辑后的JSON包进raw_text而保留旧结构；有raw_text的文本稿继续保留其余结构字段。非法JSON保留输入并显示错误，不请求保存。
- 扩写要求先保存本地修改；扩写期间禁用输入。扩写结果成为后续保存的基线，不再从最初的章节摘要重建内容。
- 未保存草稿（文字+原内容快照）存入按项目/目标隔离的sessionStorage；同浏览器标签页切换后恢复。存储禁用或配额失败仍可正常编辑，但不能保证本地恢复，未宣称服务端已保存。离开页面时有未保存内容触发浏览器提醒。
- 点击关闭先尝试保存，失败保持编辑器打开。重新加载提示放弃本地稿，加载期间禁用输入；失败保留文字。恢复草稿保持原快照，不能跳过服务端冲突校验。
- 旧数据content_json=null按空对象参与快照比较，允许空大纲首次保存。
