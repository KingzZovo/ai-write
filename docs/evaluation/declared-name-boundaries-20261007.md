# 姓名边界改用明确声明证据

日期：2026-10-07。未部署。

## 复现与改动

“导师陈川留在门外”被原有角色名正则解析为导师陈川留，后续事实契约可能误判陈川改名。问题来自把动作前的汉字串当作姓名，而非某个禁用词。

主角、导师/救援者的未知姓名现在主要从冒号或名叫/名为/叫等明确声明提取；保留主角姓名加性别的人物表写法，以及有句段起始边界的“某人是……导师成员”身份声明。自由行动句不再通过动作字作为边界猜姓名。结构化 entity_registry 仍照常读取。名字中的留、默等字不做删除，复姓四字姓名继续支持。

事实检查报告增加 scope=explicit_role_declarations_only。该检查通过仅表示未发现声明冲突，不是完整人物身份或关系验证。

## 验证与复核

32 项通过：行动句误识别、明确三字名与复姓、登记来源、真实姓名冲突、确认大纲选择与中性大纲回退等。Python 编译和 git diff --check 通过。原多人身份测试改用两条明确声明，保持对多身份警告逻辑的覆盖。

按 shadow-mind 作本地正确性与完成度复核：当前没有可信只读隔离，未启动子代理。核查全部提取器调用点（大纲一致性、事实契约构建/校验），保留注册信息和既有明确冲突回归。

## 验收边界

自由叙述的身份召回降低，这是撤销无证据硬判，不代表自由叙述已被核对。角色关系所属主体、同名/别名、否定与转述、实际中文长文仍需证据化评审。尤其有规范槽位时，多位导师是否属于同一关系不能仅凭角色称谓判断。真实数据库/CPA/浏览器未验收，未部署；没有新文学质量结论。
