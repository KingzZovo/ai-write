# 弧大纲完整规划与章节材料衔接

2026-10-09，基于`b120cf6`，仓库`/root/ai-write`。本批修复当前弧规划及保存/读取合同，尚未部署。没有生成新的模型实稿；工程测试和完整字段不能证明小说达到中文作者交付标准。

## 中文编辑标准与材料边界

继续采用[中文小说编辑标准](CHINESE_FICTION_EDITORIAL_STANDARD.md)和已保存的[Gemini规划实稿审读](editorial-planning-20261006/REVIEW.md)。本轮核对的是这些已有审读结论，未开展新的互联网采样或模型盲测。

- 姐弟稿的问题是人物怎样商量还款、信封怎样交接，而非缺少一个名为“连贯性”的字段。欠三千、交两千、余一千须保留，不能靠临时新增供货人、订单或收入把人物选择省掉。
- 救人稿需要展开正面扶持如何变为背负，以及抵岸后两人的回应；规划擅加货物损失、正文用“顺势抄起”略过关键动作，均不能由模型高分或JSON完整抵消。
- 《阿Ｑ正傳》《水滸傳》的既有合法参照用于人物选择、动作转折和前后情绪承接，不复制时代措辞或题材章法。静场可由关系和认识变化推进，结尾允许自然收束。

旧弧Prompt强制“一句话方向”，并禁止所有跨弧伏笔，无法承载上述要求。本次以完整过程、人物选择依据、开收状态和下章交接代替单句方向；承接已有长线，不强制冲突、损失、反转或悬念配额。保留合理生活细节创造，未确认的既往事实不能被写成已发生；新增可立即化解核心问题的资源/关系仍须核对。

这些是输入和工作流调整，尚不是文学改善实证。测试里的“第几次约定”等夹具只检验材料传递，不能作为合格小说样稿。

## 最终实现

`arc_outline.py`负责完整规划，`arc_loop.py`保留兼容导入及状态/brief，`arc_sources.py`负责当前来源。新请求保持原有4–40章范围，拒绝布尔、小数、字符串和越界值，不夹到另一请求；这是单弧范围，单书设计下限仍为500万字以上。

先生成元信息，再按最多5章分批展开。11章使用整体规划、1–5、6–10、11四个阶段；40章最多9阶段。每阶段最多两轮逻辑调用，每轮240秒，Registry内层修复关闭，修复继承原路由输出预算。最多18次逻辑尝试不等于18个HTTP请求，Provider原有重试/降级仍存在。每批携带完整原作者输入、前弧材料、整体规划及全部已接受前批，不截掉早章过程。

元信息必须提供准确章数、标题、主要处境、情绪发展、起止状态、后续衔接和已有线索安排。每章须准确编号，包含标题、summary、非空key_events、start_state、end_state和handoff_to_next；可保留全部结构化台账、人物选择、叙事关注点及未知描述字段，不规定最少两次外部事件。标题超过数据库500字符限制进入修复，不剪掉字尾。

严格JSON拒绝截断、重复键、非有限数字和显式异常结束，完整坏输出随原任务参与一次修复。模型不得在任何嵌套台账里注入应用身份、内部标记或作者raw_text。阶段失败停止后续，返回不可用及内存中的已接受部分；API不创建半截分卷。该部分尚无持久候选恢复，不能声称崩溃后会续接。

保存边界再次验证整个计划，作品结构锁内一次创建Volume、全部空正文Chapter草稿、完整confirmed卷纲及稳定卷章引用，并完成全书位置维护。没有生成或覆盖正文、摘要。原作者输入与原章序保存在`_arc.input_material/chapter_order`；章纲使用主线`chapter_summaries`格式，不再另存一份beats。

当前来源与卷纲编辑器采用相同的确认、版本、创建时间、ID优先级，先选该卷的当前版本，再判断它是否仍为弧。稳定分卷身份失效、卷号不一致、坏状态不自动转换或借用旧编号。状态写入和下一弧保存前于共用锁内重读完整当前来源；内容、版本、选择或卷号改变返回409，提交未确认返回503。更新状态保留完整章纲、作者文字修订、未知metadata及未知状态扩展。

新弧首次报告前，作者可明确重排同一组章节，第一条进展报告确认此时章序；已有报告后重排会停止brief及继续报告，要求核对进度，不用计数猜身份。手动提前结束的弧不能被额外报告重开。旧beats没有原身份记录，保持独立兼容路径，只接受准确唯一的整数章号与非空文字，不补造历史。

当前章brief携带完整该章过程及必要卷级安排，不把其他章事件混进本章；作者文字修订优先，旧结构及原输入保存在库中但不压过改稿。下一弧传入完整的前弧有效大纲和明确标注的作者进展；这不是自动读取并验证全书正文/人物事实。

新阶段`arc_outline_meta/arc_outline_batch`各有独立Prompt资产；首次种子继承`outline_volume`端点、模型、温度、输出预算和层级，不覆盖已配置资产，不将整体卷纲Prompt错用为章节批次。源码种子尚未在真实Registry应用，缺配置仍会明确失败，默认模型未切换。
