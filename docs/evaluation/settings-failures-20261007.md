# 设定提取失败不能伪装成空结果

2026-10-07。未部署、无新增真实模型调用。

旧三路提取只要一路返回，就把其余失败/缺失字段替换为空列表；合并提取调用失败或JSON坏格式也返回三个空列表。接口因此可能以零新增正常结束，掩盖资料不完整。

本批改为：

- 明确区分合法空列表与失败。每一路必须返回对应列表，每条资料须有非空身份字段；合并结果拒绝重复人物、关系缺失端点或自关联。不再静默丢弃坏条目。
- 三路全成功才接受；部分失败抛安全异常，API返回502并停止图写入。三路全部失败保留一次合并回退，失败仍显式报错。取消不回退。
- 异步加载已配置模型路由，避免同步getter返回未加载的默认路由；模型日志携project_id/task_type。路由初始化失败也归类为提取失败。
- 不记录原模型文本片段，错误信息不含原始上游响应。
- 原有同源快照保护、图事务和严格投影不变。本批是调用/格式完整性检查，不是人物关系在文学事实上的正确性证明。
