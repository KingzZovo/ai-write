# 分卷再生成的原子替换（2026-10-07）

旧入口在模型返回前删除并 flush 旧章节和卷纲，且流函数后部的局部 async_session_factory 导入遮蔽前部引用，使保存可能抛 UnboundLocalError。格式解析失败后仍继续存入降级卷纲，弹窗收到业务错误但流结束后仍可能调用成功回调。

## 修改

新服务 volume_regeneration 在模型前只读快照，随后释放数据库事务。快照覆盖项目、卷、已确认书纲、当前卷纲、章节与历史版本；复制书纲供生成使用。通过现有 project guarded_stream 排除并行生成，OutlineGenerator 携带 project_id。

模型完整返回后严格解析 JSON，核验目标卷、章数、连续章号、章节必要字段与一致性。不会通过补闭合符号把截断 JSON 变成可删除旧稿的依据。写入前按项目/卷/书纲/章节等父子顺序锁行并重读快照，资料变化则拒绝；旧章节与旧卷纲的删除、新卷纲与新章节的创建在同一个事务提交。已确认的成功再生成仍会替换并删除旧章与其历史，保留原有明确警示。

失败提示不泄露供应商诊断。提交结果不确定时要求刷新核对，不把所有数据库异常都承诺为未提交。弹窗仅在业务 done 且无错误时通知成功；普通 EOF 和业务失败保持可见。
