# 定点改写补齐作者与故事上下文

## 缺口

评审调用已有细纲、前后章、风格和人物认知资料，但定点改写此前只有局部原文、前后各200字符和评审建议，作者要求没有传入。定位正确不等于修改正确；局部流畅可能以人物越知情、关系变更或提前兑现后章为代价。

## 修改

新增不可变 RevisionContext，SSE与worker使用当前生成链已有的作者要求、细纲、前章事实、后章参照、风格及认知记录，不另开资料查询。改写提示区分计划与已发生事实，后章材料只供衔接，不能提前兑现；评审意见需核对，不执行与作者要求/事实冲突的建议，无法可靠修复时原样返回区间。

本章区间外完整正文作为只读上/下文，不再只取200字符。用户提示超过24000字符时跳过该区间，保留候选和对应意见，不静默裁掉要求；此为字符预算，不是供应商精确token计费或完整请求上下文上限，注册表system内容另计。

模型原样返回区间（包括外层空白被清理的情况）不计成功修订，遵循上一批未应用定点修改即停止、不升级整章重写的行为。

## 验证与复核

- 94项相关后端离线测试通过；新增4项覆盖完整上下文入提示、远处正文保留、超预算零模型调用、原样/仅外层空白回复不记成功。
- 既有10项SSE/worker生产分支测试补充核对实际传入的RevisionContext全部字段。
- 5文件AST、git diff --check通过。
- 按shadow-mind无可靠只读隔离回退，代码冻结后本地核对两个入口变量来源、上下文标签、预算不裁剪、无变化回复与上层停止语义；复核补了外层空白不算成功修改的判断并复跑。

## 尚待验收

未做新的真实Gemini/其他模型对照、完整ASGI/Celery/数据库或浏览器验证，未部署。增加材料只修复传参缺口，不证明模型会遵守，也不证明文学质量提高。较长章节可能超过此保守输入预算，应在模型实际上下文限制和完整性可验证的前提下设计分层引用，不能为提高成功率丢作者要求。

资料仍受既有上游来源/版本保护能力限制；多个不相交修订区间基于同一原稿，合并后的新因果关系仍需重新评审与编辑式审读。最终验收继续采用中文作者标准与原句证据，不用模型分数替代可读性判断。
