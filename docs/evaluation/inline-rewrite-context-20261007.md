# 选段改写上下文与结束校验

桌面编辑器及TextRewriter原先分别截取选段前后500字符，较远的人物信息、场景关系和已经发生的事件可能丢失。普通rewrite直接返回GenerationResult.text，未检查供应商明确截断。

现在桌面发送本章选段以外完整前后文；服务不再二次截断，标明只读、后文不提前成为当前事实、保留作者声音和人物知情范围。所选文本与自定义要求完整加入。系统加用户提示总长超过24000字符则明确报错，不静默截上下文；仍需后续支持超长章节的可追溯上下文组织。普通返回调用共享require_normal_finish，已知不正常结束不返回候选。

44项相关离线测试通过，包含完整超过500字符上下文到达模型、作者要求保留、超预算零调用、三种明确异常结束拒绝、真实SSE响应迭代在部分输出后出错不发送completed。供应商流关闭/结束原因相关回归同时通过。前端tsc通过，未运行真实浏览器。

本地两轮shadow-mind复核（无可靠只读子代理隔离）：调用链检查发现桌面还有一次500字截取，已同步移除；完成度检查发现续写与普通替换共用onAccept拼接、选择区变化后的版本保护需要单独修复。本轮不声称这些已解决。最终AST/diff检查通过。

未新实跑CPA、未证明中文描写质量提升、未部署。缺失结束元数据仍未知。API异常文本和旧同步路由初始化仍可进一步统一；选段与全文输入预算、续写插入语义、采用前原稿版本保护继续。无新增迁移，累计头a1001935。
