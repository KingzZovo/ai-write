# 历史人物提及记录与章节边界

## 问题与修复

过去生成上下文直接读取 character_appearances 全书累计表：改稿、删章后缓存可继续保留旧记录；重写早期章节时后文次数影响人物卡排序，后文 last_seen 还会遮住真正需要回读的早期章节。把名字出现次数称为人物“出场”也可能误导写作：正文提到某人不等于此人在场或知道当时发生的事。

新增 load_historical_roster：按当前人物名和别名，从当前章之前的 completed 正文重新统计提及记录。全书序号必须为正且在本作品中唯一，重复检测包含草稿。正文改动、状态变化、删除、移入其他作品和重编号在下一次读取时立即生效。读取禁止 autoflush，不提交或回滚调用方事务；流式读取 32 行一批，finally 关闭游标，不把整书文本集中存入内存。

一次 ContextPack 只计算一份结果，共用于人物卡排序、名册渲染、旧人记忆卡回读触发、相关章节检索。独立调用这些服务时也按相同边界读取。名册与召回理由使用“提及”，并提示口吻、外貌、状态须回查原文。

保留已有统计表供其他功能使用，没有新增迁移。既有记忆卡仍需逐条核验章节来源和原文摘录；提及记录本身不成为人物状态或知情依据。

## 验证

- 首轮 50 项针对性测试通过。
- 真实 PG/Neo4j 来源与记忆卡集成 36 项通过。
- 复核发现相关章节检索仍读全书名册，补齐后 35 项针对性通过，新增实际相关章节服务测试。
- 合成 2000 章、500 万字、100 个人物；读取前 1000 章共 250 万字耗时 1.158 秒，结果为 1000 次提及、最后位于第 1000 章，后半书未计入。这是本机单次读时测量，不是生产 SLA。
- 首轮全量 1884 passed；补齐相关章节旁路后的最终全量 **1885 passed，4 条既有 warnings，262.26 秒**。最终日志 `/tmp/aiwrite-roster-full-final.log`。

按 shadow-mind 无可信只读隔离环境的回退条款执行本地独立复核，检查所有 CharacterAppearance 读取点、章节时序、重复序号、跨作品隔离、游标释放和结果复用。复核发现并修正相关章节检索旁路。

## 边界与后续

人物别名仍来自当前人物设定，并非逐章版本化事实。统计采用精确字符串匹配，不能判断代词、同名或人物是否真正出场，因此只作为回读线索。每次构建需要扫描历史正文，避免陈旧缓存的代价是新增读时计算；后续缓存必须同时绑定正文及人物别名版本，不能直接恢复使用无来源全书累计值。

认知账本仍缺逐章来源；记忆卡创建阶段的首次出现标签仍读旧累计表；相关章节检索另有状态/伏笔信号来源需要继续治理。本批没有声称这些已解决，也没有声称文学质量验收通过。源码尚未装入 ARM 隔离镜像或正式生产。
