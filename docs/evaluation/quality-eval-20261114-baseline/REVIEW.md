# 基线编辑式审读(2026-11-14)

按 `docs/evaluation/CHINESE_FICTION_EDITORIAL_STANDARD.md` 的流程做**编辑式**审读:
先完整读正文,记录具体原句与问题,再对照场景要求核对兑现。全部分数只作辅助,
本文件不下"文学合格"的结论。

**读过的范围**:6 个场景的 `scene_writer` 正文全部通读(生产默认路径);
`chapter_single_shot` 与 `bare` 只抽样对照,未逐字审读,因此**不对这两个变体下编辑结论**。

**判定口径**:可交付 / 需局部修订 / 需重写。三档都不能用平均分抵消。

## 逐篇结论

### 1. real_ferry(现实生活·渡口姐弟)——需局部修订

问题都在"用新人和新门路解决问题"上:

- 「这样,你把这两千拿上,剩下的那一千......我明天一早去找供销社的**张阿姨**,她手里兴许有活钱,
  我拿缝纫机作抵押先借一天。」——一个从没出现的邻居加一个新抵押渠道,把缺口绕开了。
- 「我再去找供货的**老陈头**盘算盘算,看能不能先赊他两千块的货款把房租垫上。」
  同上,且"赊两千"与"缺口一千"自相打架。
- 「她太了解自己这个姐姐,答应了的事从来没有含糊过。」——叙述者替读者总结人物,应删。

可取之处:姐弟的推让有来有回,结尾「周芸站在原地…望着那艘亮着橘红色航行灯的渡船解开缆绳」
把"留在岸上"落到具体动作上,不是抽象收尾。

### 2. real_stall(现实生活·夜市摊位)——需局部修订

- **硬伤**:「可你高二的学费呢?资料费呢?**你哥**......你现在退了,以后拿什么翻身?」
  场景从未设定过儿子/哥哥。这一句凭空给这个家添了一个人,并且拿他当劝说的理由。
- 「她伸出粗糙的手掌,把那张招工简章从桌上拿起来,叠好,塞回女儿的校服口袋里。」
  这个动作比后面大段说理更有力,可惜紧接着又用对话把道理讲了一遍。

其余部分(清退通知、押金一千五、摊位费六百、母女各让一步、结尾"明早签字/赶早自习")
与要求贴合,是 6 篇里完成度最高的一篇。

### 3. fantasy_bell(东方幻想·洪水铜铃)——可交付(建议一处补漏)

- 救人过程写得清楚:摇铃、水路铺开、上背、窄路摩擦、扑上河岸,动作随处境变化,
  没有拿"几个起落"糊过去。
- 分工是人物状的:「少废话,上来!」「这回......真成穷光蛋了。」
- 缺一项背景:两人**同行三年**这层关系没进正文。不影响本场成立,但少了一层"为什么肯为他烧掉保命法器"。

### 4. fantasy_herb(东方幻想·药铺陈醋)——可交付

- 选择写足了:产妇家在门外哭求,阿棠抱着半坛醋出库房、倒进瓷碗、递出去,
  然后守到天亮看见空坛和土痕——**没有两全**,后果落到地面。
- 结尾「隔壁巷子的方向,隐约传出了几声婴儿微弱而清亮的啼哭」,把代价和结果同时交代,是这批稿里最好的收束。
- 瑕疵:「令人毛骨悚然」这类现成评语可以直接删,前后文已经写了刮擦声。

### 5. mystery_bridge(悬疑·断桥信使)——需局部修订

- 开场「**夜色沉如墨**,上游倾泻而下的洪流…」,后面又出现「如同一片随时会被吞没的落叶」。
  通用强度意象起手,是本项目历史上反复出现的同一类问题。
- 「驿站腰牌」在千余字里出现 7 次,其中「驿站的铁律森严,腰牌乃是差役的身份凭证…」
  「明日清晨卯时正点的驿站大查验,差官要逐一核对腰牌」是在替设定做说明,而不是人物在用腰牌。
- 好的一面:付不起钱时的两难具体(交牌要挨罚、不交送不到),老周的市侩有具体动作
  (磕烟杆、收起铜钱和腰牌、抓钥匙)。

### 6. mystery_lodger(悬疑·客栈空房)——需局部修订

- 苏姐用「一根薄铜片」顺门缝拨开门栓——给她凭空添了一样本事,场景要求里明说不得如此。
- 「天阴沉得像要压塌青石镇的屋檐」是同类的开场比喻。
- 「十四间房」这个设定没进正文;不影响本场,但账本/房间数是这类客栈戏的抓手,漏掉可惜。
- 信的内容(避祸、城西刘记、碎银三两)是要求里的"必须改变判断",属于允许的创造,
  而且她的判断确实从"布商"转成"在躲什么",这一步是成立的。
