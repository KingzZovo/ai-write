# 删除来源后保留核查历史（2026-10-08）

## 变更及边界

此前 foreshadow_reviews 对章节和伏笔均有 ON DELETE CASCADE。删除章节、整卷、伏笔或图谱同步清理记录时，原句证据与作者处理记录会一同消失。

新增 a1001939（父 a1001938）移除这两个来源外键，保留非空来源 UUID、快照、证据、首次处理字段以及来源版本唯一约束。项目外键继续级联：永久删除整个作品仍删除该作品历史。任务表的章节级联关系不变。记录创建和待审阅建议接受仍需锁定并验证作品范围内的有效来源。

读取时，原章节或伏笔不在当前作品可查询来源中返回 unavailable，界面显示历史证据但不允许确认；作者可忽略待审阅旧建议。已确认请求的幂等重试只承认原决定，不重建删除的来源，也不重写首次处理记录。该状态不猜测来源是被删除还是移到其他作品。

迁移检查真实约束名，PostgreSQL使用ALTER TABLE；SQLite迁移测试使用表复制。降级前检查缺失来源，存在保留历史时拒绝恢复旧的级联外键，不能通过删历史来迁就旧模式。此前已经被旧约束删除的记录不能由本迁移恢复。
