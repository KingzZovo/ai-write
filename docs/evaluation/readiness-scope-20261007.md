## 修复

共享检查先验证卷的 project_id；章节与显式 volume_id 冲突、章节无有效所属卷也拒绝。无效目标清除派生章名、卷号等数据，卷与章节层均不就绪，并返回 target_error=target_scope_mismatch 与重新选择目标的说明。请求中已有的资源 ID 不被当作归属证明。

这一检查由 API、后台章节/大纲任务、直接单次生成器和场景生成器复用。异步生成入口将目标错误说明传给客户端；正常“生成章节大纲”仍只要求全书/卷大纲，不因缺少待生成的章大纲而报循环依赖。现有前端读取 block_message，新增字段不要求前端改变才能显示原因。
