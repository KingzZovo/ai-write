- `deepseek-ai/deepseek-v4.1-flash`

## 本次配置操作及尚未恢复的监听

在私有目录保存完整配置备份后，仅向 NVIDIA 映射添加 V4.1 Flash、GLM 5.3 Flash、Kimi K3 三项，解析后验证其他字段完全相同。使用原子文件替换写入后，共享 CPA 的模型目录未出现新增项。随后发出的三次候选请求均为 HTTP 400；这些请求先于确认注册成功，不能作为模型能力评测。

进程核对：本机 8317 确由该 CPA 进程监听，工作目录就是配置所在目录；原子替换后只剩 auth 目录的 inotify 监听。独立 CPA 复现结果：

| 更新方式 | 新别名是否出现 | inotify 监听数 |
|---|---|---:|
| 启动后 | 初始模型可见 | 2 |
| 原地写入配置 | 是 | 2 |
| 原子替换配置文件 | 否 | 1 |

这确认本次原子替换触发了 CPA 的文件监听兼容问题，不只是配置等待加载。共享服务仍在运行，但配置文件的热监听已失效。测试型号没有通过，故已按原始 SHA256 将共享配置恢复；**恢复文件内容不会自动恢复丢失的监听**。监听恢复仍是本次操作遗留的待办，不能报为完成。

共享服务观察到 5 条已建立连接，无法仅凭 TCP 连接判断是否有进行中的生成，因此没有重启共享 CPA。管理配置只存密码哈希，现有已知管理凭据未找到；已向用户请求管理密码，用于查看活动状态并安排恢复。没有修改管理密码或关闭认证。

## 隔离 CPA 的实际调用

同一 CPA 二进制启动于 `127.0.0.1:58317`，独立 auth 目录，仅加载已验证目录凭据槽的 NVIDIA 通道，禁用额外重试。模型目录确认三型号注册成功后才发出以下调用。请求仍经过 CPA，没有绕过代理直接向 NVIDIA 生成；这不是共享 8317 入口的可用性验收。

| 型号/参数 | 有错稿结果 | 结论 |
|---|---|---|
| DeepSeek V4.1 Flash，2400 tokens/120 秒 | 121.20 秒 APITimeoutError | 未获得诊断，停止控制请求 |
| GLM 5.3 Flash，2400 tokens/120 秒 | 98.33 秒 LLMEmptyCompletionError | 应用按上游返回计数判断输出预算已耗尽，但文本为空 |
| Kimi K3，2400 tokens/120 秒 | 121.10 秒 APITimeoutError | 未获得诊断，停止控制请求 |
| GLM，请求 `enable_thinking=false`，2400 tokens/120 秒 | 121.26 秒超时 | 未证明参数有效或质量改善 |
| GLM，8192 tokens/300 秒 | 301.24 秒超时 | 较大预算仍未得到正文，故不能将故障仅归因于预算 |

所有调用已结束；复现结束后只向隔离进程发送 SIGTERM，进程退出、58317 不再监听。没有终止共享 CPA。没有评审内容可按中文编辑标准评价，不给这些模型做文学排名，也不把目录更新当作备用模型修复完成。

## AI-WRITE 评审预算修复

隔离库的 `chapter_evaluation.max_tokens` 实为 **8192**，但 `ChapterEvaluator.evaluate()` 固定传入 `max_tokens=2400`，盖掉 Registry 配置。移除这个调用层覆盖，交由现有路由使用任务配置；不另设新的配置来源，评审总超时与请求超时仍保留。

已有真实 PostgreSQL/Registry 测试补上实际调用边界的预算断言，验证配置 3000 时不会被 2400 覆盖。初轮全量 1874 passed/1 failed；失败是旧测试要求源码必须含 `max_tokens=2400`，该静态断言已移除，由上述配置传递验证取代。最终针对性 **41 项通过**，全量 **1874 passed、4 项既有 warnings，263.61 秒**。测试总数少 1 是移除旧的源码字面量断言，不是跳过失败的行为测试。日志 `/tmp/aiwrite-evaluation-budget-full-final.log`。

按 shadow-mind 的隔离要求采用本地独立复核。正确性复核确认只移除输出预算覆盖、超时和失败处理未变；架构复核确认继续使用唯一 Registry 配置和现有路由预算解析。较大配置可能增加输出、延迟和调用成本，本批恢复用户已有设置，不宣称能消除上游超时。

预算修复尚未装入 ARM 常驻镜像；隔离应用仍运行上一批 `scene-boundaries-candidate`。CPA 监听恢复、有效备用模型、文学验收与正式上线继续保留在计划中。
