# 前台分场生成中断后保留片段

旧前台在分场输出部分正文后失败，清空缓冲区并发fallback_restart，切换整章单次生成；只有第二次也失败且片段超过200字才保存残稿。这会把已展示给作者的文字换成另一份正文。

现在任何已交付非空片段后的异常都不触发第二模型调用，保留collected_text，标partial_draft_only并进入既有草稿保存流程；不重发已有文字、不重置客户端缓冲。generation_interrupted事件说明内容可能不完整，partial_saved原因改为partial_generation_interrupted。没有任何片段时保留原有单次回退。移除200字保存门槛，不因片段短就丢弃。

22项离线/AST分支测试通过，覆盖零正文回退、短残稿/多场残稿不回退、不重复发文及既有关闭和后台残稿逻辑。更新相关预期后，4项原有数据库API用例收集成功，未执行，故不能声称真实草稿落库验收通过。
