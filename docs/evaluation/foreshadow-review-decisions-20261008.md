# 伏笔建议首次处理记录（2026-10-08）

## 实现

确认/忽略建议时，在同一数据库事务中保存 handled_at（UTC）和 handled_by（已验证 JWT 的账号）。认证中间件只在验证成功后设置 request.state.auth_username；开发禁用认证的请求没有已验证身份，保留为空。接口不接收客户端自报处理账号。处理账号表示登录账号，不等同于真实姓名。

重复确认或忽略沿用首次决定，不重写账号和时间；失败事务同时回滚状态、处理记录及确认涉及的伏笔变更。新迁移 a1001938（父 a1001937）仅增加两个可空字段，不用创建时间猜测旧处理时间。历史界面显示处理账号和本地时间，旧记录明确显示“未记录”。
