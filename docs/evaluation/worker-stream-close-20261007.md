# 后台流关闭与初次残稿保护

后台书纲、卷纲、初次场景生成、整章修订四条流原先裸async for消费。现在显式aclosing，取消或进度保存异常退出消费时关闭下层流。

检查时发现初次场景生成失败后的第二次尝试共用collected，收到部分文字后重试可能拼接两份正文。两类异常（超时/普通错误）现在先检查已收片段：已有片段停止重试；循环后保留任务result_text/progress_text原文，status=needs_review，generation_stop_reason=partial_generation_interrupted，并返回，不进入整章fallback或后续自动验收/写回。提示明确片段可能不完整。没有文字时原有重试策略保留。

46项离线/AST测试通过：执行真实_consume_scene_stream分支，在进度保存失败/取消时立即关闭底层；执行初次重试循环验证两类异常收到正文后仅一次调用；中断保存分支逐字保留并return；已有整章修订/定点停止/任务保存工具回归同时通过。不是完整Celery与真实数据库集成；本次不保证提交故障时新恢复记录一定能落库。
