# 正文与场景编排流关闭

前序路由层显式关闭尚不能保证上层生成器的关闭会传入。ChapterGenerator.generate_stream、SceneOrchestrator.write_scene_stream与orchestrate_chapter_stream原先仅async for转发。

三处现在以aclosing拥有下层流；编排层关闭时立即关闭当前场景，不继续后续场景或把未完成场景记入下一场上下文。参数与正常生成文本保持不变。

71项离线测试通过：新增三种入口读取首段后显式aclose、立即清理且仅开启一个提示流；同时回归注册/分层路由关闭、场景编排、场景规划契约及普通生成结束校验。新测试使用真实服务方法，ContextPack/规划/提示调用为替身，不等于数据库或供应商集成测试。

按shadow-mind本地复核（无可靠只读子代理隔离）：资源检查确认三层yield均被关闭上下文覆盖；流程检查确认关闭时不执行循环后当前场景汇总及下一场。AST/diff通过。

未实跑完整generate API或Celery取消，无法证明浏览器断连能及时到达这三层。上层SSE/worker转发、任务持久化和真实计费停止仍待核验。未部署、无新正文质量证据，无新增迁移，累计头a1001935。
