## 问题与结果

此前弧规划实际输入只有本次作者材料及前弧，提示中的“保留全书事实”没有对应全书输入。原始立意、当前书纲和登记规则可能全部缺失，尤其是长书纲中段约束，后续修复也无法补回。

现在作品标题、原始立意、题材和原目标字数，当前所选完整书纲，以及 PostgreSQL 登记世界规则进入元信息、全部章节批次、修复和恢复。来源原件与实际提示全文分别保存；书纲中段、原始换行和规则全文不裁剪。仅读取所选书纲全文，历史候选只在锁定选择时读取 ID，不读取整书正文。

书纲按确认状态、版本、创建时间和 ID 选择，作者当前文字修订优先于旧结构。坏当前书纲、空文字修订、错误 raw_text 类型和空规则正文明确停止；不能回退到更旧结构伪装材料齐全。空规则分类允许，显示“未分类”，不损失正文。

## 范围与剩余工作

此处 `world_rules` 是 **PG 读投影**。本批保护这份副本的读取及实际输入，**没有核对当前 Neo4j 或原书纲提取版本**。图谱规则编辑后的 PG 更新/删除助手仍是 best effort，可能留旧值；弧规划和写作的这条规则来源需继续治理。

人物状态、关系、认知、正文事实和未完线索尚未接入弧规划。当前材料明确标为创作设定与计划，不证明过去已经发生；不把无来源的 `settings_json.book_synopsis` 或运行配置当事实。单书设计下限继续为 500 万字以上，后续按有来源的记录和有界召回接线，不向每个 Prompt 灌整书正文。

无新迁移，源码单头仍为 `a1001958`，累计迁移未在真实 PG 应用。真实数据库竞争、图谱/队列与 worker、前端行为/浏览器、固定 CPA 连续章文学验收及部署/回滚仍待完成。
