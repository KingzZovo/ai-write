# 人物记忆读取使用持久化章号

日期：2026-10-08。未部署。

确认读写差异：character_states、认知、角色位置和历史正文查询按持久化 Chapter.global_idx 取来源；ContextPack 以前把章节数量偏移用于这些查询，虽另有 history_before_global_idx，也未用于全部人物读取。删除章节后两者可能不同。

现在 build() 校验持久化边界为正整数，将其同时写入 pack.global_chapter_idx/history_before_global_idx，并传给人物状态、认知、历史出场、相关章节和叙事线等现有读取。缺失持久化位置时停止构建。旧偏移只通过独立 foreshadow_chapter_idx 参数进入旧 planted_chapter 年龄计算，避免把尚未迁移的旧伏笔数据用另一编号解释。

68项离线回归通过，包含实际 build() 参数传递、实际 _build_facts 中状态覆盖/历史名册/认知与债务参数不同的测试（持久化31，旧偏移11），以及无效边界、旧债务、必要事实和角色筛选回归。Python编译和git diff --check通过。新增测试使用查询适配器，未验证真实PG删除/重排事务。

按shadow-mind作本地正确性/完成度复核，无可信只读隔离未启动子代理。核对实际变量 gidx 的消费者和旧债务唯一参数入口；生产 build 总是提供持久化章号，历史直接调用 _build_facts 的默认兼容路径仍只适用于两套编号相同的情况。

未完成：旧伏笔写入与存量 planted_chapter 的统一迁移、缺失章号修复、重排/删除后各投影的时间线一致性、真实跨卷模型验收。此处只消除旧偏移用于记忆查询的混用，不宣称整套编号或长篇连贯性已经完善。未部署。
