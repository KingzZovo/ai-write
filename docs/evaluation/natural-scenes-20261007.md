# 按情节分场与前场原文连续性（2026-10-07）

## 修复依据

《六本台账》1800 字任务在原链路中强制至少三场、每场至少 800 字，预算最低变成 2400。第一场已交钥匙并离场，后场又重复交接。旧上下文只留每场末 600 字，却将计划 key_action/transition_bridge 当作已发生状态；预约时间等前段事实丢失，计划结果可能被当成事实。

## 实现

- 允许 1..20 场；有明确场数建议时作为参考，无建议时按自然转折选择，不再按目标字数强制最低三场。
- 保留短场预算（例如 300 字）和完整短章单场（例如 1800 字），取消 800 字下限及 1200 字上限。每场技术预算范围调整为 1..6000，并保留既有整体预算检查；这不承诺模型一定写满。
- 允许相同地点、时间和持续动作跨场推进。只要求实际状态向前变化，不再要求相邻场动词与受事不同，不为凑字段差异添加情节。
- 后场读取本章全部已写前场正文，不截取末 600 字、不附加“计划已完成”的结论。全章作者要求明确按场景分工落实，不要求每场重做全部事件。
- 新增中文场景规划/续写默认提示词，首次缺少该任务时由 Registry 增量种入；已有资产不被启动逻辑覆盖。规划明确可以自然收束、不强制每章高潮/钩子、缺失事实保持未知；正文重视时间、物件、知情和汉语动作/感官的准确性。
