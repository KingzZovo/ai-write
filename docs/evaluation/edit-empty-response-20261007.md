# 改写与风格润色空响应处理

本轮先检查同步get_model_router引用是否使用旧配置。公共ModelRouter._current已在实际调用前刷新受管理实例，既有路由刷新测试通过，因此未重复修改初始化。

发现选段改写和StyleAgent普通/档案润色会将空文本正常返回，流式全空白也可正常EOF。新增共享require_nonempty_text/require_nonempty_stream，在三个服务入口的普通与流式路径拒绝全空白；有效正文的原始空白不清洗，不改已有异常类型。流式校验器使用aclosing管理被消费源。

51项离线测试通过，覆盖六条空白路径、有效正文与空白逐字保留、源正常结束关闭、传输异常不被重分类、实际rewrite SSE响应在空流后返回error且不发送completed，以及上下文/风格材料/代理错误/路由刷新回归。未实跑外部模型或浏览器，也未声称模型空响应根因已修复。

按shadow-mind本地复核（无可靠只读子代理隔离）：正确性检查确认有效文本不被strip后返回，原传输异常先于空判断传播；调用链检查确认rewrite SSE捕获异常而不发完成事件。API仍可能先传空白片段，但界面不可把其作为成功正文。消费方提前关闭整条调用链的集成取消行为不在本次证明范围。

未新增迁移、未部署，累计迁移头a1001935。实际路由可用性、完整运行环境与中文文学质量验收继续。
