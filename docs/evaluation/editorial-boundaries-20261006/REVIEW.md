## 方法与范围

固定本机 CPA 配置中的上游，使用隔离 aiwrite_quality_eval 数据库及应用 Registry/cache。geminiweb 请求别名 gemini-3.1-pro；温度0.3、max_tokens3200；未启用规划。baseline 是 ../editorial-prose-20261006/candidate-prompt.txt 的上一轮精简候选，不是线上默认合同。candidate-prompt.txt 区分作者确定事实与可以创造的现场细节。两题沿用前批，archive_receipt 为本批新题。每题每版本只有一次采样，不支持统计排名。

三篇修订将原设定、实际候选稿和具体编辑意见合并输入（revision-cases.json），不是同输入横评。审读者为 Codex，知道模型及版本；不是真人作者盲评，也没有借助模型评分判定合格。逐篇完整阅读，以原句、人物与场面效果判断。

输入输出原样留档；results.json 记录哈希、字符数及耗时，字符数含标点/空白，不冒充中文净字数。上游返回 token usage=0 表示未提供有效计量，不能认为免费。请求别名不能独立证明底层模型身份。DeepSeek/Claude 使用同份 candidate 输入，失败不记为文学不合格。

## 编辑式审读

### 渡口姐弟：候选需重写，修订仍不合格

可取处：信封压碗和回避谈钱让关系冲突有可见载体；修订的两次五百元还款方案比初稿外借、抵押、退布多线并起更集中。

候选先说“还差两千块”，随后又说“算上两千，还差一千房租”，两处不能同时成立；修订保留原错。读者被迫重新计算账目，姐弟的难处因此失去可信基础。新添姐夫、邻里经济状况、工具抵押和退布退款承担了解困功能，已不是无关紧要的生活细节；结尾又约次日县城碰头，给返镇交租新增路程而未处理。第三人称限知周芸，却直接写“他知道这法子折腾人”。

baseline 有较完整上船动作，却先让姐姐说“明天一早，我把这两千先给你带去”，结尾弟弟已带钱离开。修订虽然收束枝节，但“那我回去向房东再申请宽限两天”由姐姐提出，混淆谁应去谈弟弟的店租；“申请恐怕通不过”也不像此处姐弟自然口语。

调整应先固定欠款与交租缺口，保留谁拿钱、谁去协商及是否尚未获准，再围绕两人如何开口修写。不是再补一套财务字段让人物背诵。

### 铜铃救援：候选需重写，修订仍不合格

baseline 将半年积蓄改三年，新增腿卡石缝却未解除就背走。candidate 恢复半年，但“内息催动”“几个起落”临时把普通行商写成有功法的行动者；“俯身一背”省掉本题最重要的伤者如何上背。危险形容不少，关键场面反而不清楚。

修订增加健腿蹬、翻上背，但先将胳膊架在脖颈、又让许舟双手撑石，姿态转换含糊；“转身踏上光路往回走”后又“一步步向岸边退去”，朝向不稳定。前句掌心铜渣，后句“空无一物的双手”没有中间动作。最终台词“看账本你精明，算脚力你糊涂”只是把背景职业贴成一句俏皮话，没有从共同脱险的反应中生长出来。

“连个响都没听见”可能是口语夸张，不单独当作机制硬错；但上下文刚强调铃声压过水声，此处含混也没有人物语气支撑。水路的色泽可以创造，水压破坏机制、内息前提则会改变已给规则。应按已设窄路与伤腿写足必要动作，允许普通准确动词重复，不必升级战力或堆叠灾难词。

### 档案领料单：需实质修订

可取处：原件归还、编号抄录、后续申请未批都大体保留，场景能向前推进而不宣布破案。

candidate 开篇“过了保质期的报纸”“钥匙……发出轻微的凉意”搭配不准确。赵师傅说“数字从来就没完全合上过”，越过作者限定的知识边界；直接叙述他的内心“他太清楚……”，也越过许宁限知视角。两版均把清单日期擅自具体化为采购/开工日期，改变证据意义。

修订修好了两处措辞，却保留“开工日期”和“他看这年轻人态度坦诚”。赵师傅继续替许宁解释账目，再由许宁表示明白，削弱了她自己收住判断的成长。父亲关系的初始顾虑被删弱，十分钟由许宁自己提出，也没有完整兑现原场景转折。应让她在原始数字和日期前修正自己的判断，用赵师傅的可见回应显示态度变化。
