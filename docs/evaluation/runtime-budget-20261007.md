按原文核对：错稿将八点复诊改为八点半，并直接进入非视角人物的内心、触觉；两轮都没有报告。正常稿中作者明确安排陈川接钥匙、明早与站长共同核对后封存。基线评审却把“无权批准封存”扩张为“无权接收保管钥匙”，这个前提不在作者要求或正文中，属于误报。引用“行，钥匙留给我。”虽可逐字核对，也不能证明其诊断成立。

候选只在请求末尾补充通用规则：权限按具体动作判断，缺少批准权不自动禁止准备、搬运或临时保管；不得扩张已有权限限制。候选本例误报消失，但仍漏真实错误，没有足够证据证明稳定提升，**未写入源码、Registry 或默认配置**。不得把对照稿满分当成候选通过，更不能把错稿满分作为正文合格证据。
