# 大纲来源伏笔可按主数据来源管理

日期：2026-10-08。未部署。

source=lifecycle伏笔只存在PostgreSQL，但更新/删除/手动兑现接口原先必须先找到Neo4j节点，导致记录能在面板展示却可能操作404。

三种操作现在先以作品ID、伏笔ID、source=lifecycle和FOR UPDATE定位PostgreSQL主记录，直接修改或删除并flush，由既有get_db事务依赖提交/回滚。手动兑现属于作者明确确认，重复确认返回400。没有匹配的lifecycle主记录时继续原有图谱流程，不把不明来源记录擅自切换主存储。
