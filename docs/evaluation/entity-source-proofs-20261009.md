## 实际行为

- 每次仍读取当前实体记录、作品/卷章身份、标题、保存状态、全书位置和数据库写时正文指纹。缓存不保存正文或可变的状态/关系载荷。
- 首次必须以完整非空正文核对来源；存在引文时还须逐字匹配。成功证明只绑定完整来源receipt摘要及确切引文，同一章的多个待核引文共用一次全文读取。
- 已验证的确切版本可以复用；改稿、改标题/卷章/作品、改状态、删章、重复全书位置、不同引文、未知指纹或淘汰后重新校验。坏引文不能借无引文证明通过，空正文不能只凭元信息通过。
- 当前/未来/外书来源先过滤，避免未知指纹触发无用的正文读取。元信息与全文之间发生改稿不能创建旧证明，数据库失败继续传播；读操作不提交或丢弃作者尚未保存的修改。
- 共用 `source_proof_cache.EvidenceProofCache`，实体与认知使用独立实例；默认各32768项，线程锁保护LRU。缓存记录的是不可变校验摘要而非随时间变化的事实；只有重新读取的完整当前来源仍相符才复用，淘汰和进程重启后的回读属于预期成本。
