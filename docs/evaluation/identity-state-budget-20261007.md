# 姓名记录不能替代人物当前状态

日期：2026-10-07。未部署。

事实契约仅包含核心身份和登记姓名，但 ContextPack 原先只要存在该契约，就把角色卡设为可选预算项。预算紧张时位置、实力、关系和心理状态可能被省略，模型却仍收到“唯一事实契约”的最高优先声明。

本次将已加载角色卡设为完整保留的必要块，与姓名记录分别占用预算；不足时沿用显式 ContextBudgetExceeded。契约文案说明仅记录身份、不替代状态、同类身份可属于多人，且不应覆盖作者本轮明确修订。移除登记姓名前80个的静默截断，交由现有上下文预算整体处理。

验证：包含来源与生成入口的34项回归通过；补强预算压力夹具后，最终预算/事实契约19项通过。覆盖受伤、位置、关系在身份契约存在时仍保留、无法装入时明确失败、超过80人不丢姓名、作者要求优先提示。Python编译与git diff --check通过。

按shadow-mind做本地正确性/完成度复核，无可信只读隔离未启动子代理。核对必要块预算机制及事实契约实际字段，未把提示改动当成模型实际遵循的证据。

限制：大量角色现在可能更早触发预算不足；需要按章节相关性选择并保留事实来源的检索方案，不能称已支持超长书。当前卡片来源时效、角色别名、显式改名任务与旧规范槽位校验的协调仍待处理。没有真实模型/数据库或文学质量验收，未部署。
