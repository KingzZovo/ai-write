# 多人物身份不再按姓名顺序强行归一

日期：2026-10-07。未部署。

## 改动

角色档案的 role/type/identity/身份/定位字段以前用子串匹配，“不是主角”和“主角的父亲”也可能成为主角槽位。现在仅识别去空格、大小写归一后的明确身份标签；同一档案出现多个不同标签时不强行选一个。来自多个角色的同类身份先收集姓名，只有唯一候选才填补大纲未指定的槽位；不会按角色查询排序挑第一人。已确认大纲中的明确槽位仍优先。

没有规范槽位而正文出现多名同类身份时，改为 role_identity_ambiguous 警告，不再仅因“导师有两人”判定姓名错误并阻断。这个警告表示需要关系层面的理解，不代表已证明全文无错。

## 验证与复核

23 项通过，覆盖否定描述、关系描述、单档案多标签、多人同身份、倒序输入、明确中英文标签、确认大纲优先，以及既有事实漂移和大纲一致性回归。Python 编译和 git diff --check 通过。按 shadow-mind 作本地正确性/完成度复核；无可信只读隔离未启动子代理。

## 重要边界

本轮测试最初使用“导师陈川留在门外”，既有正则提取为“陈川留”，暴露动作字被吞作姓名的独立问题。为单独验证多身份判断，测试改用能明确识别两个人名的“导师沈听澜在门内。导师陈川在门外”；正则问题仍未修复，不能把测试通过当作名字提取已可靠。

规范槽位与正文人名的硬冲突判定、多个关系的所属主体、源档案歧义提示及正则证据定位仍待继续审计。没有新模型样本、真实数据库或中文文学质量验收。
