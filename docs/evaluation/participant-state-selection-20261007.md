# 明确相关人物不再因卡片数量上限丢失状态

日期：2026-10-07。未部署。

现有 _cap_character_cards 先按本章提及和历史出场排序，再硬截到卡片上限。超出的本章人物只保留姓名，位置/伤势/关系消失；前章交接正文也未参与相关性选择。

现在本章大纲、已有正文及已提供的紧邻前章正文中提及的人物保留完整卡片，允许超过 CONTEXT_PACK_MAX_CHARACTER_CARDS。上限作为补充人物的目标数量，历史出场频率只填剩余名额。完整提示预算仍生效，必要状态装不下时明确报错。名册说明并非所有上下文人物都应出场；配置注释同步更新。

26项离线测试通过，覆盖五名明确人物超过上限、历史高频补位、小角色表不变、上限1时仍保留本章与前章交接两人状态、预算回归。Python编译与git diff --check通过。按shadow-mind作本地正确性和完成度复核，无可信只读隔离未启动子代理。

边界：仍为姓名子串匹配，不是实体关系推理；别名、同名、被提及但不出场的人物还需校准。前章材料本身仍是已有带标注范围，不能补回未提供的前章全文。多人同场可更早触发总预算不足；真实长书召回、数据库和模型输出未验收。没有部署或新的文学质量结论。
