# 章节记忆的时间边界

本轮修复限定于检索时间边界，不代表文学质量验收或完整事实一致性已完成。

## 已修复

- `memory_chronology.resolve_history_boundary` 从当前作品/卷/章唯一定位 `Chapter.global_idx`。缺失、重复、非法或其他作品的目标返回未知边界，不以卷内章号或即时章节总数代替。
- ContextPack 的历史检索边界独立于伏笔计算的旧回退逻辑。摘要、正文片段必须 `0 < global_idx < 当前章`；压缩记忆必须 `0 < source_global_idx_max < 当前章`。查询端范围过滤后再验证返回元数据为正整数。
- 旧版 HierarchicalMemory 的相关摘要同样传入持久化边界；卷级摘要只取当前卷之前的卷，作品和目标卷均在 SQL 内限定。
- 压缩器读取全部 scroll 页，按全书章号排列，只压缩章号明确的数据，保留最近部分；新压缩结果记录来源全书章号最小值/最大值。
- 本机 qdrant-client 不再有 `.search`。这两条记忆查询兼容 `.query_points`，保留旧客户端接口适配；实际本地 Qdrant 查询覆盖新 API，避免 Mock 掩盖接口失效。
- 未知目标不妨碍参考书三路召回。
