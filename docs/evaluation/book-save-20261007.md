# 整书流式生成保存保护

2026-10-07。本批未部署；隔离运行仍 c4b4a4b，生产未更新。

## 改动

- 新增 `backend/app/services/book_outline_save.py`。准备提示词前保存项目行及全体书纲行的摘要；保存时按项目→书纲顺序加行锁、强制刷新缓存并重新计算。期间项目设置/书名/篇幅、旧书纲内容/确认状态或候选集合变化即拒绝保存。
- 新稿作为 `max(version)+1` 的未确认候选创建，保留旧书纲、旧确认和下游正文；单次事务提交，不调用模型完成解析。
- 普通生成可解析正文中的分卷计划；阶段生成要求有效计划。拒绝空正文、无效计划格式、重复/不完整卷号、非法章数、错误结构；模型structured不能覆盖规范正文/计划/一致性报告。无计划的普通旧接口仍可保存纯文本候选，由已有向导处理规划。
- 整书加入与卷纲/细纲相同的项目生成互斥；模型调用前释放读事务。移除大纲后台保存任务集合和shield，所有大纲直接等待保存/清理完成，再释放项目锁。
- 阶段报错即停止保存；缺少done或空正文不能进入成功完成。saved/completed只在提交成功后发送。取消可能发生在提交已完成之后，客户端仍应刷新确认实际结果，不能把断流本身解释为数据库一定没保存。
- 将无实例依赖的 `_extract_volume_plan` 改为静态方法，避免仅解析文本却创建模型路由器。
