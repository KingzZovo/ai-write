# 生成读取会话边界（2026-10-06）

## 已实现

ARM 隔离链路首次实测存在 63.445508 秒 idle-in-transaction。SSE 入口读取风格/大纲/相邻章后没有及时结束事务，场景服务也把装配上下文使用的同一会话传给长时间模型调用。

- 新增 generation_context_session：传入 None 时创建自管短会话，校验大纲并构建 ContextPack，离开作用域即关闭；异常或取消同样释放。传入已有会话时不提交、不回滚、不关闭，保留调用方的事务所有权。
- ChapterGenerator 单次/流式及 SceneOrchestrator 支持该边界。自管上下文完成后，模型 Registry 接收 None，使用已有的独立路由快照读取机制；正文名册诊断也使用短读取会话。
- SSE 初次生成、单次兜底和整章改写使用自管模式；入口完成全部前置读取后 rollback 自己的只读事务。生成后保存继续使用已有独立保存事务。
- db=None 现在仍会进行真实大纲完整性检查，不再意味着跳过就绪校验；两个只测试串流拼接的旧测试明确 mock 大纲检查。

## 范围与后续
