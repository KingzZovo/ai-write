# 风格来源隔离（2026-10-06）

## 问题与修复

隔离 ARM 运行样本《六本台账》未选画像却继承最近更新的全局仙侠画像。后台解析、新建作品、生成面板均把“可选/启用”当成“作者已选择”。

- 新画像默认 `library`；历史 `global` 视为资料库。保留画像内容、ID、启用状态和作品显式保存的 ID，不批量猜测或改写历史选择。
- 全局默认必须通过绑定 API 明确设置为 `default_global`。旧客户端 POST `global` 兼容映射到该级别。多个候选取最近明确设置且启用者，普通编辑/画像重建不改变选择时间；停用后回落到前一启用候选。
- 作品保存的画像、章节绑定、作品绑定优先；明确作者档案不叠加无关全局默认。显式画像仍按既有规则直接加载，包括历史停用画像。
- 前端去掉第一份启用画像的自动选择，清除选择时同时清除旧 default_style_profile_id；空选项说明会使用作品绑定/明确全局默认。
- 风格页提供资料库和全局默认选项、再次设为全局默认按钮，以及书/章绑定目标输入。API 校验 UUID 与目标存在性；书级仍兼容作品和参考书两种旧语义。
- 从档案重建已有画像只更新内容，保留作者绑定及默认设置时间。

这是解析语义变更，无数据库 DDL。历史全局行没有“用户绑定”和“自动创建”的可区分凭据，无法可靠保留旧全局默认的隐含意图；若需要全局应用，应在风格页明确设置一次。已有作品保存的选择不受影响。
