# 摘要保真修复与中文原文对照

本轮实际阅读全文为鲁迅《阿Ｑ正傳》第二至四章（7438字符），并单独使用第四章（2812字符）：https://www.gutenberg.org/cache/epub/25332/pg25332.txt 。样本文本及输入/原始输出/清理后摘要/耗时均归档。合并三章是中段省略压力样本，不冒充真实单章验收或全题材评测。

## 已采用的工程修复

- 摘要请求使用完整章节，不再保留前4200+后1800字而丢掉中段。模型上下文不足时仍应报失败，不用缺失来源冒充完整输入。
- 不再只保留第一段，不再在220字符处截断输出。使用2048输出token预算，但这不证明供应商未提前终止：GenerationResult尚未提供finish_reason。
- 完整JSON/围栏被安全解包。保留中文、段落、引号、合法转义；允许字符串内直接换行。损坏JSON不再用unicode_escape猜取局部文本；重复字段、非字符串摘要、未闭合围栏、NUL/非法Unicode拒绝。
- 输出格式无效时保留完整来源与原始失败输出修复一次；仍失败返回空结果，无半截摘要。

## 真实模型实验

固定本机CPA配置里的geminiweb上游，模型别名gemini-3.1-pro，temperature=0.3，两组都max_tokens=2048。系统提示使用仓库内置summary定义，不是生产数据库Prompt快照；脚本直接走项目OpenAIProvider，不写生产配置/评测数据库。它是隔离摘要对照，不是完整生产流水线。

初轮2样本×旧/候选共4次；按读原文发现的问题调整候选后复测2次，共6次完成。每次成功只表示收到可解析文本；没有模型评分器。

## 按中文编辑标准核查的结论

**所有摘要均未达到可靠前情记忆验收标准。** 新候选更长、覆盖更多步骤，不等于事实可信。

- 第四章旧版将“质了二千大钱”写成“变卖棉被”。典当与卖掉改变后续能否赎回的状态，不是可以忽略的同义改写。
- 初候选第四章保留了先逃到舂米场、又去看热闹、再逃回土谷祠的路径及五项条件，比旧版更完整；但仍省略四百文酒钱和二千大钱，还将“在厨房吸烟、随后去舂米”的行动地点混为“厨房舂米”。
- 初候选合并样本将“大家也还怕有些真”写成“大家因他是赵太爷的本家”，把猜测/叙事反讽坐实为关系事实；又用“不久后”替换原文“此后倒得意了许多年”。
- 修订提示补充财物数额、传言/反讽、时间及动作地点后，第四章保留二千大钱和红烛规格，却仍漏四百文，并把阿Q的短工写成“长工”。后者改变职业与雇佣关系。
- 修订合并样本又添加了吴妈“严词拒绝”：原文只有惊呼、发抖、大叫跑开，不能补出没有的言辞；“洋钱不见”也被写成“被抢走”。它仍出现“不久”，并丢失二次离场过程和部分赔罪义务。

两版候选均保存为独立文件，**未进入默认_USER_TEMPLATE**。默认提示恢复到此次变更前版本；上述已验证的完整输入/无破坏清洗/不截断修复保留。实验表明继续增加概括提示，不能代替逐项来源核对。后续需要来源证据与义务/资源/行动状态核验，以及未见题材和连续章样本。
