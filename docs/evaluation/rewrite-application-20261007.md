# 选段改写采用语义与原稿保护

原先所有操作统一替换选段，续写可能删掉原选段；结果采用使用当前编辑器文本加旧偏移，生成期间作者修改正文后可能写错位置。

新增rewriteApplication纯函数，采用前核对章节ID、完整原稿快照、合法区间和选段逐字一致，空候选不采用。continue插入选段末尾，其他操作只替换选段，前后文保持字节不变。不猜测新位置，不做同名/近似匹配。桌面选择时保存源正文与章节，前后文从同一快照构建；重选递增sessionId作为菜单key，旧菜单卸载取消请求。原稿变化时提示重新选择，不执行自动保存。

RewriteMenu将实际发起的operation传给采用回调，仍在加载或错误时禁止采用；后端续写提示明确只输出新增文字，应用端负责保留原文。

5项前端测试及tsc通过：插入与替换、章节/上下文变化拒绝、非法区间、空结果，组件层验证实际续写操作传递及流式失败后禁止采用。6项后端上下文/截断/SSE测试通过。未运行浏览器或跨端并发测试。

按shadow-mind本地双视角复核（无可靠只读子代理隔离）：文本边界检查确认续写保留选段及后文、改写不改区间外字节；会话检查确认新选区重挂载、旧响应不能进入新实例。全文比较是当前内容快照核对，不是数据库版本号CAS，也不检测编辑后又改回同文的历史。远端并发与自动保存事务保护另待验收。

模型可能仍重复原文或新增错误事实；本次没有语义自动验收或真实中文新样本。未迁移/部署，整体优化继续，累计迁移头a1001935。
