## 逐句判断

a 的“沾着泥点的布鞋”与末尾“皮靴踩在水泥地上发出闷响”指向同一人物，中间没有换鞋，诊断成立。模型把它归到 action 而非 state，不影响这条诊断的实质。

a 开头已将木质闭门板扣在窗口正中央，后文仍直接隔窗递钥匙，没有明确的递物口或开板动作。需要作者澄清路径，不能由评审擅自假定另有开口。作者要求是沈青有限视角，而“陈川伸手接过铜钥匙，金属齿尖硌在掌心”直接进入陈川触觉；模型没有指出这两处。鞋履的明确矛盾与路径的需澄清项，应区别表述。

c 先写沈青收好包、出门、走到大厅门口，再看见陈川已坐在驾驶座；这些动作允许陈川在其间移动。读者不需要每一步开门上车的说明才能理解，没有同时占据两个位置，也没有被锁住或无法通行的条件。模型却要求补动线，属于误报。正文并未写发动机已启动，评审自行加了这个前提。

c 的第二条证据为“‘行，钥匙留给我。’……沈青……拔下钥匙……”式拼接，不是原文连续子串。即使程序拒绝这条引文，第一条仍能定位；因此“至少一条引文存在”不足以确认整个推断正确。引文定位只能证明来源，不能证明因果诊断。

## 决策

- 不接入自动修订或验收。先证据提示能在 a 找出一个旧评审漏报，但不能据此宣称已解决事实审核。
- 后续实验须同时保留有错稿与合理省略对照稿；区分解析失败、请求失败、来源不符、误报、漏报。
- 记录标准档回退模型已下线的问题。该回退未修改；不能凭这一次失败私自选另一个生产模型。
- 实际稿件仍需按中文编辑标准复核：人物意图、动作因果、事实连续、视角权限、事件完成程度与语言表现分开判断。模型评分与计数不充当文学验收。

## 下一批机械门禁修复设计（尚未实现）

代码审计发现问题分布在多个层次，不能只豁免一个停顿词：

1. `chinese_prose_mechanics_checker.analyze_chinese_prose_mechanics` 把大量词频、句式及比例直接纳入 `passed`。其中 story_bible 检测只有通用词表，没有本书秘密设定；limited_pov 等正则也没有实际视角上下文。它们应当是观察线索，不是确认的事实错误。
2. `chapter_quality_gate._quality_penalty` 又用这些指标为候选稿排名；仅修改 `passed` 仍可能鼓励删细节和压短正文。须同步取消以形式计数认定“改善”的路径。
3. 生成前提示、`CHINESE_PROSE_MECHANICS_PROMPT`、`contract_hard_gate_prompt` 和改写提示重复强制清零、固定对白比例、微动作配额及无条件生活惯例；须一并改为受作者要求和原文证据约束的编辑指导。检查 Registry 已存资产，种子更新不能冒充运行时更新。
4. 明确区分形式观察、结构污染疑点与存储安全检查。原有 meta 检测会匹配正文中的“第几章/卷”，须验证人物正常谈论书籍的情况，不可不分语境全部删除。空输出、截断、拒答及作者版本保护仍须保留。
5. 保存状态和界面不能将“机械检查未阻断”表述为“文学合格”。保持正文与评审来源绑定，不能通过放宽形式门禁让旧评分自动洗白这些已发现问题。

验收须覆盖：正常停顿/长对白/回忆/必要重复不触发付费改写；真实结构污染与存储安全仍受保护；候选稿不因计数下降而被替换；上述两份真实失败稿保留事实问题；API/场景/整书使用同一语义，随后进行隔离 ARM/CPA 及界面实测。
