# 参考风格统计与正文配额分离

## 实际缺陷

ContextPackBuilder._render_style_profile 为任何 dosage_profile 写入固定7000字章节、27字对白轮长、“句尾比喻是江南特色，多用”、口语骂人要求和每章心理套语上限。缺失统计按0渲染，坏字段可能丢掉整个统计块。规则/反AI/语气/统计被拆成四块，to_system_prompt 的 [:3] 会静默丢弃第四块。

这些要求不是当前样本支持的结论，也不符合用户要求的中文作者/编辑验收。已有《阿Q正传》《水浒传》实际阅读对照（见 CHINESE_FICTION_EDITORIAL_STANDARD.md）表明，重复要看叙事作用，句段长短与对白应服务具体人物和场面；不能从命中次数推断人物深度。

## 修改

- 新增 style_reference_observations：仅输出有值、有限、非负的有效指标；对话占比限定0到1。单个坏字段不吞掉其他有效字段，缺失不等于0，实测0保留。
- 标为样本描述，明确不是本章目标、上下限或合格线；人物身份/关系/视角/场面优先，不为接近数字增删文字。
- 移除固定章长换算、虚构对白均长、作者风格归因、口语骂人要求、通用套语硬配额及把普通词语一律当任务泄漏的禁令。
- 一个选定档案的规则、反AI要求、语气和统计合成一个参考块；保留总体上下文预算控制。作者显式规则保留，参考原文仍不注入。
- AGENTS.md 的旧剂量/双向区间说明标记为历史，防止后续把它恢复为通用质量门槛。
