# 场景附加提示冲突修复与 CPA 替代模型复测

日期：2026-10-07。生产未部署；本批没有修改默认模型或已有 Prompt 版本。

## 源码修复

上一批统一写作合同已允许普通合作、自然省略与作者指定的明确结果，但 SceneOrchestrator 在实际调用时又拼接了相反要求：任何到场/换手等都要有路径或代价；新增实体必须有见证信息；支撑不足一律降为疑点。应急模板也仍要求机制成本、局部胜利与末章钩子。

本批移除这些重复限制，保留关键事实和承接检查。规划台账明确标为“尚待正文落实”，不能覆盖作者要求或已发生正文；未来封存不应提前变成本章义务，已经要求确认的结果不应强行变成疑点。应急分场仍默认关闭，显式使用时保留完整作者来源，不额外套上冲突、成本、动作次数上限或悬念。

独立复核又发现 `hook` 为空时会自动写“本场为末场，需送入本章钩子”。空字段既不能证明这是末场，也不应触发悬念；已改成按本场任务自然收束，不提前结束全章。
