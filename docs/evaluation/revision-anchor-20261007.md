# 定点改写的引用与段落定位

原 locate_revision_span 使用 find 的第一次命中，重复对白/叙述会选错位置；仅按双换行分段导致单换行章节被当成整段；跨段引用只定位起点，可能没有包含完整引用。

已要求非空字符串引用且原文中唯一命中（包括重叠命中），不使用模型猜测的段号消除歧义；明确 quote_verified=False 的意见不进入定点改写。按原字符串的单换行、双换行、CRLF非空段定位，覆盖引用经过的全部段落再扩展前后一段，返回原文坐标，不先归一化换行。真正过长的连续段落仍受原有改写上限保护。

验证：services/test_targeted_revision.py、test_c2_auto_revise.py、test_auto_revise_rollback_preserves_draft.py 共62 passed。新增13项覆盖重复/重叠/空白/非文本引用、三类换行跨段引用、未核实引用无模型调用，以及长章节局部替换且其余原文完全一致。原超长段落测试改为真正无换行的长段，保留其预算保护语义。2文件AST、git diff --check通过。

代码冻结后按shadow-mind无可靠只读隔离回退，本地核对唯一命中、跨段边界/切片偏移、合并改写区间与上层调用行为。没有发现需要进一步改动本轮定位的结果；发现上层在无定点结果时仍可能整章回退，另列待办，不把局部保护误报成整个改写链已安全。

未完成：SSE与异步上层仍保留整章回退，未定位意见在该路径上的证据门槛需要独立修复；合法的全章结构问题或缺失事件也不一定有唯一引文，不能简单丢掉所有无引文意见。本轮未新增真实模型生成、数据库/浏览器验收或部署，不能证明修订后的文学质量。源文本若用硬换行折行而非实际分段，需要在输入层另行明确段落表示。
