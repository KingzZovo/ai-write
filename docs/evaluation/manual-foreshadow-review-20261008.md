# 已保存草稿主动伏笔核查（2026-10-08）

本轮完成桌面/移动工作区 → 伏笔面板 → 主动核查接口 → 持久任务执行器的入口。

- POST `/api/projects/{project_id}/foreshadows/review-jobs` 接收章节 ID 和编辑区完整正文，锁定作品范围内的章节，要求正文逐字匹配已保存稿；空稿、生成中、未知或重复全书位置拒绝。
- 核查显式允许 draft / needs_review / completed。实体与认知调用仍默认仅允许 completed，不将核查过的草稿自动升为正式事实。
- 复用同来源且没有更新通知的最新活动任务；完成或失败后主动提交可建立新周期。与保存通知共用 `entity_source_outbox_revisions` 序列，章节锁串行化手动提交，提交事务成功才向界面确认。
- 执行器和失败重试支持草稿，并保留执行前/落库前来源、版本及令牌校验。
- 界面精确发送编辑区文本，显示保存冲突，确认成功后刷新任务；章节切换、内容变化及卸载使旧请求的界面反馈失效。结果是待作者审阅的伏笔建议，不代表整体文学质量合格。
