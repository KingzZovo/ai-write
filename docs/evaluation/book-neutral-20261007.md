# 大纲题材与篇幅适配（2026-10-07）

《修补以后》5400 字短篇的旧大纲膨胀到 8929 字，现实修书故事使用“修为、功法、反噬”栏目，五个人物被逐一安排创伤。实际调用快照确认：Registry 前缀只有阶段说明，强制配额来自 outline_generator 阶段模板及 user 追加要求。

## 修改

九段公共内容由单次和阶段入口共享。人物数量按剧情需要，背景只解释当前行动，次要人物可简写；人物可以通过手艺、判断、关系或情绪发生变化，不要求升级、惩罚或创伤。现实环境按工作、物品、时间与制度描述，幻想要素只在题材需要时展开。伏笔可以是日常承诺与情感呼应，不要求谜团或续卷悬念。

同步取消阶段调用中的五个人物、三至五势力、固定 1000/500/1800 字扩写要求。完整性检查仍要求阶段职责对应的编号段落有正文，骨架有有效 volume-plan；技术性过短响应阈值按项目目标篇幅降低，长篇保持原阈值。字数阈值不作为文学质量评分。

异步整书入口现在将项目目标总字数、每章字数及卷章偏好传入 scale，也接受任务显式 target_volumes/target_chapters_per_volume 正整数。修正规模说明中写死的“100–200 章/卷”，避免三章短篇收到自相矛盾的指令。

## 实测后标题兼容修复

阶段解析接受纯文本或 Markdown 的编号标题（含水平缩进和一至六级标题）；仅去除编号之前的标题标记，保留每一段正文及分卷计划。实际失败骨架零模型回放已识别一、三、七、八、九及一卷三章计划。22 项针对性通过（3.81 秒），包括普通/Markdown/缩进标题的内容完整保留；全量后端 2010 passed，4 项既有 warnings，318.57 秒。

按 shadow-mind 本地独立复核检查阶段归属、正文边界、首尾切片及缩进正则，未发现新增阻断问题。粗体包裹标题等其他格式未扩展，本次兼容以实际观察到的 ATX 编号标题为范围。新标题修复尚未部署，准备在部署后创建独立重试任务；不会重复提交正在运行的任务。

编辑判断：人物小传更聚焦当前行动，不再给每人安排童年创伤，也不再用修为/功法表描述修书；主要客户承诺与林禾离店后的安排仍在。字数减少本身不是合格依据。

仍未合格：world_logic_contract 在世界段和全文尾部各出现一次，且重复填写与现实故事无关的删除/审查/跨卷规则；旧书的去向被明写为“不额外指定”，第三章关店后由谁保管、移至何处缺少衔接。既定事实必须守住，但完成剧情所需、作者未限定的普通收存动作可以合理设计，不能以不补设定为由留下可见缺口。
