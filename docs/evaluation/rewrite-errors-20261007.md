# 选段改写错误反馈

旧rewrite SSE直接把str(exception)发送前端，用户可能看到供应商内部错误；TextRewriter初始化在try之外，初始化失败没有同样的结束错误反馈。

新增rewrite_errors：预算异常有独立类型，明确空响应、截断、超时、未知异常映射固定code和中文error。保留前端已使用的error字段。初始化移入try，错误路径始终不发送completed，随后发送DONE。日志只记异常类型，不在这条日志中记录异常正文。取消仍按BaseException传播，不误报普通失败。

28项离线测试通过，包括五类映射、初始化/半稿后异常的实际SSE响应迭代、私有诊断字符串不出现在响应、无completed，以及上下文、空白响应与风格Agent相关回归。前端无需修改，沿用既有error回调禁止采用失败候选；真实浏览器未复验。

本地shadow-mind两轮复核（无可靠只读子代理隔离）：错误边界检查确认响应仅固定消息/代码，服务不写原文所以原文未修改提示成立；兼容性检查确认error字段与DONE保留，新增code不替换旧字段。未改变批量生成错误路径，其他API异常治理不在本次范围。
