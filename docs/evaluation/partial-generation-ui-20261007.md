## 问题与修复

后端顺序为 generation_interrupted → saved → partial_saved；前端原先忽略首尾事件，可能把句子完整但章节未完成的残稿标为 completed。保存失败或未收到确认时，收尾还会恢复旧正文。

前端现在在中断时记录草稿约束，但不声明已保存；普通 saved 到达也保持 draft。partial_saved 独立确认持久化并显示“本章尚未完成”。保存未确认时保留编辑区片段，提示复制备份并刷新核查，不更新 lastSavedRef。零正文回退提示改为“尚未收到正文，改用整章生成”。
