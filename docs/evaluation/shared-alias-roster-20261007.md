# 共用别名不再被归给排序最前的人物

日期：2026-10-07。未部署。

count_appearances 原先按姓名排序遍历别名，首次遇到即写入唯一归属。两个人都登记“老陈”时，所有该称呼的历史提及会被算给其中一人，并可能改变 last_seen、旧人回读与角色筛选排序。

现在先收集所有登记归属，唯一归属才记入确定次数；多人共用的别名匹配范围会被消费，但不记给任何人，也不会让其中包含的短姓名被重复计数。未跟踪的角色不能借先前插入的别名成为合法统计主体。明确姓名优先、重复登记去重和长词优先保持；等长匹配顺序固定。

38项离线测试通过：映射顺序倒置、共享别名、包含短姓名、同人重复别名、未登记主体、实际 load_historical_roster 对最后提及章号的影响及既有别名/回读回归。数据库读取使用适配器，未做真实PG集成。Python编译与git diff --check通过。

按shadow-mind作本地正确性/完成度复核，无可信只读隔离未启动子代理。核对实时历史读取会调用新计数器；已持久化的 chapter_style_stats/角色出场聚合没有在本轮重算，需部署后按既有重算流程验证更新。

这是字符串提及统计，不是确认人物实际在场。共享别名在具体剧情中即使可被读者消歧，当前统计仍不分配；不能把少计的确定次数当作不存在该人物。单字称呼、姓名本身与他人别名重合、复杂指代仍有局限。没有新小说产出或文学质量结论。
