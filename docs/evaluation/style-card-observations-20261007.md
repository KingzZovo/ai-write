# 参考书切片风格汇总修复

## 依据与变化

ContextPack 的参考卡片回退入口曾用最长文字代表句式/对白/节奏/情绪，用集合投票选视角/时态（平票顺序不稳定），将不同切片的感官缺项按零参与均值，并把聚合结果渲染为“禁忌与招牌”。这些推断既不证明哪个描述更好，也可能把参考书的视角与口吻强加给当前章节。

新增 style_card_observations，保留不同描述及其出现片数，同片重复标签只计一次；按出现次数和文字稳定排序，各维度最多列3种并注明省略。视角/时态作为样本记录，明确服从本章既定要求。样本中回避的表达与常见手法仍可参照，但不自动成为本章禁令。

感官各项仅接受0到1的有限有效数值，缺失不补零，实测0仍计入；各自按有效片数求均值并展示分母。不把字符串误拆成词汇标签，不把异常字段序列化成提示词；带空白的感官键忽略，避免同一维度重复计数。超过5项注明省略。

数据库仍取最早top_k张卡片，增加id作为时间相同的排序次键；没有声称这是全书代表性抽样。提示词明确“切片观察，不代表全书”，合成单块后仍受ContextPack总预算控制。
