# 润色候选任务来源校验

此前候选只保存任务原稿摘要，详情API不返回校验信息，润色文本也没有输出摘要。现在PolishCandidate.metadata额外保存candidate_hash；详情读取返回polish_provenance，分别比较task.result_text与原稿摘要、task.polished_text与候选摘要。逐字含空白计算SHA256，改变任意文字报告changed，旧记录/坏元数据报告unknown，不回填或追认。

scope固定task_texts_only，仅表示该任务保存的两份文本与记录相符。它不证明当前章节/大纲未变化，更不证明候选质量合格。移动端切换标签保留待复核，展示时补“历史润色候选，请与当前大纲核对，尚未自动采用”。

22项后端离线测试通过，覆盖双向摘要、空白改变、缺失/异常结构和直接详情API响应；前端tsc通过。没有实际PG落库/刷新或浏览器验证。读取不调用模型，不暴露内部任意元数据，只返回固定状态值。未新增schema，旧任务保留原样。
