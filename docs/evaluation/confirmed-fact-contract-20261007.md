# 事实契约只采用已确认的全书大纲

日期：2026-10-07。未部署。

build_fact_contract 原先只按版本号选取全书大纲，导致新生成但未确认的候选可覆盖作者已经确认的主角等身份记录。现在仅选当前作品、book 层级、is_confirmed=1 的记录，按版本、创建时间、ID 降序确定来源；没有已确认大纲时不使用草稿，角色表仍作为登记来源。source 区分 confirmed_book_outline+characters 和 characters，不伪称存在确认来源。

验证：中间版本 14 项通过；最终事实契约相关 8 项通过，Python 编译和 git diff --check 通过。新增测试执行生产函数实际生成的查询 SQL，在隔离 SQLite 表中验证高版本草稿、其他作品、卷大纲均被排除，以及无确认稿和同版本排序。不是 PostgreSQL schema 或运行时验收。

按 shadow-mind 做本地正确性和完成度复核，未启动缺乏只读隔离的子代理。已查两个调用点：ContextPack 注入和后台生成校验均走同一构建器，无需重复修改查询。未改变直接传入 payload 的契约提取函数。

后续仍需审计：角色档案推断唯一槽位、多人同类身份、提示词事实优先级、世界规则/权威契约加载容错，以及真实中文产出。该修复仅保证大纲确认边界，不证明整套事实判断或小说连贯性达标。
