# 章节摘要入口收敛（2026-10-06）

本批仅验证工程事实：摘要请求使用完整来源、写回绑定来源、失败如实报告。未做新模型调用，不代表中文小说质量通过；CPA/Gemini候选结论仍见 summary-integrity-20261006/REVIEW.md。

## 修复

- HookManager 与 HierarchicalMemory 的章节摘要复用 chapter_summarizer/Registry。删除4000字截断、旧模型路由、正文前200字兜底和无来源凭据的私有向量写入。
- 带作品/卷身份的入口先查唯一章节；缺失/歧义/作品不匹配返回失败。查询保留ORM来源快照，查后移卷由已有CAS拒绝。expected_content确保派发正文与保存正文相同；生成中改稿继续受CAS保护。
- 无身份的纯文本摘要只生成文本；身份缺一项则失败，不以不完整身份写记忆。
- IncrementalSync先验证正文已保存；拒绝目标待提交修改。生成一次摘要，提交PG后再投影同一份摘要及来源指纹；投影前重新验证当前DB来源。模型失败、并发改稿、向量失败均不报成功。
- 小于5%的编辑不再当成无关变动；一个金额或否定词的改变也须刷新记忆。只有完全相同的输入跳过。
- 实体阶段目前只抽取诊断、没有写Neo4j：明确 entities_updated=false，整体 partial_sync，不再冒充全部完成。
- 编辑同步API核对作品/章节归属。
- 卷纲级联仅更新 outline_json，不用预期剧情覆盖章节事实摘要。
