# 整书认知语义召回与当前候选保护

2026-10-08。基线 `96625f6`，本批实现、离线验证和冻结本地复核完成，未部署。AI-WRITE 整体修复与文学验收仍未完成。

后续更新：活跃旧来源/旧逻辑编码器清理、同书索引互斥及冷构建复用已完成代码与离线验证，见[索引治理报告](cognition-index-cleanup-20261008.md)。下文保留本批当时的测试与范围，真实服务、召回/文学质量和部署仍未验收。

原先认知提示主要按人物标签和章序选择，远处相关信息可能进不了提示；多轮修订还可能继续使用首轮节选。本批在全体前章来源核对之上接入独立的认知语义索引，并让每轮评审和局部改写重新准备当前候选的材料。相似度只选择参考材料，不把人物的怀疑、误信或旧时未知改成客观事实。

## 实现与调用合同

- `character_cognition.load_ledger` 的快照覆盖完整前章集合、章序、来源、实际认知载荷和作者决定，包括有效空结果。目标章同时提供 ID 与原全书位置时，两者必须一致；检索期间换位不能沿用原数字窗口。
- 写作和评审使用 `load_prompt_context(..., defer_retrieval=True)`。全部历史能放下时直接返回完整字符串；放不下时返回不可直接字符串化的 `CognitionPrompt`，保留独立副本、完整查询材料和快照。默认不延迟的接口只保留数据库诊断节选用途。
- 调用者先结束收集材料的数据库事务，再解析认知提示；解析后重新核对全书快照和嵌入配置。借入的活动事务会被明确拒绝，检索模块不会擅自提交或回滚调用者的写入。这个保证只涉及新增认知检索，其他已有 RAG 网络 I/O 尚未整体迁出事务。
- `embedding_space` 从现有路由配置克隆专用 provider，避免跨事件循环复用共享 HTTP client 或锁。完整材料按最多 4000 字符、重叠 120 字符分片，每批最多 32 条；拒绝截断配置和非 float 编码。响应按 index 还原，缺项、重复、越界、布尔索引、空/零/非数/非有限向量和维度变化均不能作为成功。
- 逻辑编码器指纹绑定供应商类型、模型、端点和编码配置，不包含 API 密钥；查询与历史片段使用同一次配置快照。该指纹不能证明上游同名模型别名从未替换实际模型。
- Qdrant collection 按作品、编码器和维度隔离：`chapter_cognition__<projecthex>__<space64hex>__<dimension>`。不可变点 ID 绑定确切事件和片段；payload 只存版本及身份摘要，不存正文或引文。
- 每 256 个 ID 检查已完成片段，缺失部分每批 32 条嵌入，最多 4 个协程逐批写入。中断后可复用已确认片段。查询仅允许当前快照的点，按 `event_key` 分组、每组取一个命中，防止长引文的多个片段挤占全部召回位；返回数量、组 ID、payload 和分数都须核对。
- 提示优先保留焦点人物与读者的最新完整记录。旧命中与该人物最新记录、读者最新记录成组取舍；事实与完整引文不能截断，必需记录放不下就停止。不同事实不会因文字相似自动合并，最新一条也不被代码解释成某人物的完整知识。
- 检索和重验共用 180 秒期限；请求拥有的资源在收尾时分别最多等待 5 秒。取消传播，失败不变成空材料成功。未配置嵌入时不会使用旧路由的零向量回退。

## 接入口与复核修复

普通/流式正文、分场写作、手动评审、后台评审和质量检查均在调用模型前解析认知材料。后台六处正文生成由拥有事务的调用者先提交，再以独立短会话准备；后台评审在检索前后检查租约。质量检查也收到完整待评正文及认知记录，资料失败返回不可用状态。

冻结复核发现并修复了以下问题：

1. SSE 与后台修订原先只读首轮认知。现改为每轮评审、每次局部改写前重新调用 `load_candidate_context`；使用完整当前候选，SSE 等待期间持续心跳并正确关闭任务。准备失败保留最新候选，后台不会经异常保全退回更早的初稿。
2. 初次正文缺少必需上下文时，不再切换生成方式重复同一故障；整章修订遇到该故障也停止重试。错误提示区分缺失提取、来源变化、容量不足和检索配置问题。
3. 旧 `generation_runner` 的评审和改写不能复用规划 checkpoint 中的首轮材料。现逐次构建新上下文，把完整候选加入检索并作为本章已有内容渲染；恢复评审同样重新准备。多候选分支每份新稿前刷新材料，认知失败不再吞成空评审；候选评审前先保存首稿 checkpoint，失败保留已交付首稿。
4. 非认知资料失败的质量检查不再误提示作者补提取认知。

`cognition.cleanup_deleted_projects` 每小时扫描严格匹配本模块名称的集合，批量核对作品存在性，关闭数据库会话后清理永久删除作品；回收站作品保留。数据库失败不会成为作品不存在的证明，周期扫描也能处理删书后的迟到写入。**活跃作品的旧来源和旧编码器向量回收尚未实现。**
