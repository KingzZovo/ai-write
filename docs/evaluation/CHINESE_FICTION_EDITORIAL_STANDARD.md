# 中文小说编辑式验收与首轮对照

2026-10-06：按用户要求，文学质量以中文小说阅读体验和原文对照为主要依据。自动评审只作辅助。以下是 Codex 的编辑式审读，不冒充真人作者盲评，也不代表所有中文作者的审美共识。

## 验收方法

先隐藏版本、模型名及评分，完整阅读正文，再记录具体原句、阅读效果、问题原因及最小修改建议，最后查看细纲核对兑现情况。分别判断“可交付”“需局部修订”“需重写”，不以平均分抵消人物、场面或叙述的根本缺陷。

| 维度 | 中文小说阅读标准 | 常见不合格表现 |
|---|---|---|
| 人物 | 欲望、顾虑、选择和说话方式形成具体的人 | 换掉人名仍毫无区别；人物代作者解释规则 |
| 场面 | 关键冲突、选择、转折及后果有可感的过程 | 铺陈很多，关键动作一句带过；把过程写成操作说明 |
| 语言 | 词义和搭配准确，叙述口吻统一，细节有用 | 任务术语泄漏、翻译腔、堆比喻、抽象情绪总结 |
| 节奏 | 详略服务于本场关注点，有紧张与缓冲 | 所有动作等长；机械插入环境和微动作凑比例 |
| 对话 | 符合身份、关系和当下意图，有回应或回避 | 人人同腔；双方复述已知背景；强行信息碎片化 |
| 连贯性 | 行为承接记忆、关系、情绪及现实状态 | 事实没错但人物态度重置；段落之间缺少情绪承接 |
| 完整性 | 本章承诺兑现或有明确、有效的转折后果 | 到关键处戛然而止冒充悬念；卷末不处理核心冲突 |
| 阅读驱动力 | 读者关心人物或局势的下一步 | 每章固定神秘人/新纸条；没有实际变化的悬念 |

事实与因果错误仍是底线，但全部无错不等于小说合格。人物的错误信念、不可靠叙述、反讽、留白和合理省略不能机械判成作者逻辑错误。静场可以依靠关系与认识变化推进，不必每段新增外部事件。结尾可以回响、余味或情绪落点，不强制悬崖式悬念。

## 已实际读取的互联网参照

鲁迅《阿Ｑ正傳》，Project Gutenberg #25332，第二章“優勝記略”及第三章前段。访问日期 2026-10-06。

- 原文：https://www.gutenberg.org/cache/epub/25332/pg25332.txt
- 版本页：https://www.gutenberg.org/ebooks/25332
- 只用于分析具体叙事技巧，不把鲁迅的措辞、反讽口吻或时代用语变成玄幻/悬疑/科幻统一模板。该电子版有注号及疑似录入杂字，不据单字异文建立语言禁令。
- 维基文库普通页面访问403；孔乙己 raw 响应只取得页头，未得到正文，因此不列为已读比照作品。

第二章先写阿Q的处境及自尊，再通过受辱、自我开解、赢钱失钱、打自己，把同一性格推到新的窘境。短句“他睡著了。”能收束这一段，因为前面的行动已完成心理转折，不需要另添悬念物。第三章受辱后欺负弱者，前场情绪直接变成后场行动，形成跨场连贯。

可迁移的是：用具体选择显示性格；重复发生时改变处境与意义；高潮后允许简洁收束；场景之间承接人物的情绪驱动力。不能迁移成“所有人物都自欺”“每章都写受辱”，也不能要求角色的自我解释客观正确。

## 对现有真实生成稿的编辑式审读

样本来自 context-pressure-20261006，原始500字压力探针；不是完整章节，也不是同题材对等基准。

### fantasy_cost-candidate.txt：需重写

- “河水如野兽般咆哮”“像无形的巨手”“如低沉的雷鸣”“如潮水般流失”：连续使用泛化强度比喻，意象互相争抢，没有形成清晰、独特的渡河体验。
- 同伴始终只有抓衣、呼救、喘息，主角只有施术和坚持；没有可辨识的关系或当下顾虑。救到了人，不等于写出了值得关心的救人场面。
- “铜铃瞬间化为灰烬，彻底消失，再也无法重现”重复替规则作保证；铜铃的重要性没有转化为人物的选择与失去。
- “两人交接完毕”把救人写成任务流；“内心涌起复杂的情绪”没有给读者具体感受。
- 调整方向：围绕既有设定中真实的顾虑安排选择，写清救援转折及抵岸后的关系反应，压缩重复强调；不凭空添铜铃身世或人物关系。缺少必要人物背景时补规划输入，而非让正文临时编造。

### mystery_bridge-candidate.txt：需重写

- “那只缺失的左手空荡荡地垂”指代和动作矛盾；应准确区分残臂、袖口和不存在的手。
- “他必须用行动来展示断桥的阻力和解决办法”是写作指令，不是人物当下经验。
- “断桥的形成阻力和危险显而易见”不像信使危急时的口语。守卫和信使都在反复解释秘密不能泄漏，对话没有形成可信的试探或交换。
- 结尾停在取金币，读者等待的送信场面没有交付，也未构成一个成立的失败转折。
- 调整方向：先确定两岸站位和双方诉求，以具体问答与动作推进信是否交付，把关键转折写足；删除规则复述。不能只把抽象词替换成华丽词。

## Prompt 与工作流调整队列

1. 将规划字段保留在规划层；正文层提供必要事实、人物诉求、本场转折、叙述视角与目标风格，避免重复灌入整套抽象规则。
2. 审查 narrative_contract.py 的固定对白比例、连续短句数量、每章比喻数量、强制最强悬念收尾等通用限制；改为场景适配建议，并检查下游门禁是否仍按旧配额误拒绝。先做隔离候选对照，不直接声称默认修改有效。
3. 细纲补足“读者此刻关心什么、人物为何这样选择、关键场面在哪里、场末发生什么变化”；不要求正文把这些字段解释出来。
4. 定向修订顺序：场面/人物/转折 → 段落详略 → 句子语言；避免只去套话而保留空洞情节。
5. 建立题材分别匹配的合法可访问样本；本轮只有一部文学小说参照，不足以验收网文、玄幻或科幻。补悬疑信息控制、幻想行动场面、长篇跨章关系与卷末兑现的对照，记录出处及范围。
6. 用未参与调参的完整章节及连续章节做盲序对照，记录编辑修改量和具体改善/退步。模型高分不能覆盖编辑式审读的不合格结论；用户意见优先。真正真人盲评需明确标注参与者，不能由另一个模型评分冒充。

当前结论：两篇旧探针按中文小说标准均不合格。后续候选及实测见各批 REVIEW.md；截至 editorial-boundaries-20261006，尚未证明可将新候选设为默认，P5继续未完成。


## 补充参照：《水滸傳》的行动场面

访问日期2026-10-06；Project Gutenberg #23863，原文 https://www.gutenberg.org/cache/epub/23863/pg23863.txt 。本版第二十二回“橫海郡柴進留賓　景陽岡武松打虎”，实际阅读范围从武松读告示至打虎后遇猎户；不同版本回目编号可能不同。

- 武松读告示后想返回，却担心被店家耻笑。危险选择连着人物的自尊，不是作者单纯命令他进入战斗。
- 虎扑、掀、翦，武松反复“闪”；重复的动词对应不同来势与站位，保持动作清楚。不能把“重复核心动词”本身判成缺陷，也不应强迫换成生僻近义词。
- 哨棒折断后改为揪、按、踢、打；手段随着处境改变，读者看得到为何要换动作。战后力竭表现后果，不靠抽象宣称付出代价。
- 本电子版哨棒折断处疑有缺文，缺少碰撞对象；不把这一处缺口当成可学的省略技巧，也不默默用其他版本补齐。

迁移到铜铃救援的判断：需看清受伤者如何上背、负重者如何在窄路调整方向；普通步伐无需逐步报数。可以保留准确的“扶、背、退”，不必用“几个起落”“光刃”等词制造强度。古典小说只提供动作与人物组织的参照，不要求现代白话采用其时代措辞。

## 批次方法与允许的创造

“先隐藏版本”的流程是后续盲序验收目标，不表示所有已做探针均为盲评。editorial-boundaries-20261006 为明确知道路由的 Codex 编辑式审读，无真人作者参与、无模型分数投票。天气、衣着、停顿等未写入细纲的细节可以合理创造；新增亲属、经济来源、机制或既往事件若改变核心冲突，需单独核对。口语夸张、反讽与人物失言不能仅凭字面矛盾判硬伤。
